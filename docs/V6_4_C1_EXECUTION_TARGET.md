## 4. 参数化：最多四个连续变量加一个已有参考类型

### 4.1 活跃区间

关键区间继承 B.3 的 slot 2；前驱区间为任务定义中、slot 2 之前最近的合法 active 区间。选择只能依赖冻结 TaskSpec 与原区间 mask，不能看候选执行结果后改选。

有前驱时：

`x = [z_prev_e1, z_prev_e2, z_key_e1, z_key_e2]`，单位 m。

没有前驱时，退化为关键区间二维问题，明确 `active_dim=2`。关键区间本身不合法时，任务为 `NOT_APPLICABLE`，保留该任务与各方法槽位，不换另一个任务。

把 x 嵌入原 `z[6,2]`，未开放区间严格为零。每个开放区间满足 `||z_i||_2 <= 0.020 m`，不是四维总范数限制，也不是各坐标分别 20 mm 的正方形限制。

### 4.2 参考类型

`family ∈ {v1, v2}` 是已有离散类型。一个候选使用该 family 对应的完整原 definition；不在本轮引入逐区间混合新类型。

不要把“前一段有偏置”描述成跨锚点连续保持偏移。保护窗口仍恢复原基础参考，允许前一段影响后续状态不等于偏置跨过保护窗口。

### 4.3 API 输入输出（待实现接口，不是现有命令）

输入至少包括：

- 冻结 TaskSpec 及哈希；
- `PreferenceSpec`：A 或 B、固定质量窗口/几何范围、B 的 0.030 m 偏好；
- 冻结 execution/config identity；
- 初值规则、搜索参数、总候选预算；
- 独占 run root。

输出至少包括：

- `status`，`selected_plan` 或 null；
- family、完整 z、active intervals、definition/plan SHA；
- `prediction_task_passed`、在线守卫结果、偏好判定；

## 5. 两种偏好的精确定义

### 5.1 固定评价范围

每个任务在候选生成前固定：

- `W_key`：原关键区间；
- `W_support`：前驱与关键合法区间的并集，不连接中间受保护窗口；
- `W_full`：完整 0–27 s；
- `route_obstacle_id`：本轮改变位置的那一个原球障碍；
- `related_pair_ids`：原策略中连续体几何与该球对应的原生碰撞对。

所有方法使用同一任务的同一窗口。不能根据候选非零支撑或 observed 最小值重新裁剪窗口。

保留原 `I_route_key_legacy`，并新增 `I_support`。由于本轮开放了前驱区间，优化采用固定两段并集的 I_support；这是显式的新指标版本，不得把它与旧 key-only 的 3.27%/1.03%直接比较。另报 I_full，检查代价是否转移到窗口外。

### 5.2 命令修正指标

沿用原标量语义：

`du = 原速度盒裁剪后的名义17D速度 - 实际选中17D命令`。

`I_support = sqrt(mean(||du||_2^2))`，样本为 W_support 内已消费的规划时刻。

保存两个源向量、10D/7D 分量和同一时刻，复算与原标量一致性。不要称其为能耗、单障碍专属代价或原始未裁剪最优速度差。

### 5.3 完整路径与相关净空

`L_full` 为使用 fresh 原生 2 ms 状态计算的完整连续体末端位置折线长度；`L_support` 可另报，不替代 L_full。

`d_support` 为 W_support 内原生保存状态、冻结 related_pair_ids 的最小有符号距离。必须按同一当前状态刷新几何，不使用过期运动学缓存。不以末端点—球距离、整机全局最小值或参考净空替代。

保留最小 witness、时间、pair、截断状态和查询数。未测/缺失写 null 加明确状态，不能写 0 或默认通过。若查询返回截断下界，只能依据其正确界意义作偏好判断；不能当成精确距离优化。

### 5.4 偏好 A：低干预

只在完整 27 s、原 Task 满足且名义执行守卫无失败的候选中排序。搜索评价资格与最终独立认证分别记录。

- 首要：最小 I_support。
- 返回 strict minimum 及其值。
- 实际选择的工程并列组：以 strict minimum 为锚，I_support 不超过该值 +0.001 rad/s。
- 并列组按 L_full、系数范数、family 固定顺序、候选 ID 排序。
- 不作链式并列扩张；tie-band 不是统计等价或安全容差。

### 5.5 偏好 B：净空约束下的短路径

仅在上述预测执行资格满足、且 `d_support >= 0.030 m` 的候选中最小化 L_full，随后按 I_support、系数范数、ID 精确排序。不得借用安全残差容差把 29.x mm 判成达到 30 mm。

若没有达到 30 mm 的候选：

- 搜索期间可用完整候选的净空不足量 `max(0, 0.030-d_support)` 选择后续搜索中心；
- 最终 `selected_plan=null`，状态为 `PREFERENCE_UNMET_WITHIN_BUDGET`；
- 可返回 `best_safe_diagnostic`，但不得自动下发它冒充偏好 B 的成功计划；
- 不得将该状态写成 Task 本质不可行或碰撞。

两偏好都没有完整预测资格候选时为 `NO_ADMISSIBLE_PLAN_WITHIN_BUDGET`，不是已证明不可行。

### 5.6 多目标教师

保存完整质量向量和有限非支配集。strict、tie-selected、偏好 B 可用集合分开，不先加权成一个隐藏评分。

不把不同路线平均成一个标签；零残差最好时应保留。缺失、失败和仅预测数据不冒充已验证成功示范。

## 6. 连续搜索算法：每任务十二槽，两偏好共享

### 6.1 四个初值，占用前四槽

1. v1，全部 z=0。
2. v1，关键区间按冻结几何方向远离路线球 12 mm，前驱零。
3. v2，同方向 12 mm，前驱零（正式几何基线）。
4. v2，同方向 20 mm，前驱零。

几何方向仅依据任务中的球心、基础参考和横向基计算，不读取该任务未来 actual。方向恰好无定义时使用协议固定的规范方向，并记录退化；不能根据试跑择向。

原 28 行只可用于开发说明和固定通用初值规则，不允许以测试 task_id 查询历史最优结果。

### 6.2 后八槽：有预算的交替坐标轮询

使用无需新依赖的有界直接搜索。每一次提案都从当前已经评价的候选出发，不调用新的网络或第二个控制优化器。

推荐确定性实现：

- 偏好中心按 A、B、A、B……轮流选取，共至多八个新槽。
- A 中心由 A 当前排序决定；B 优先使用已达 30 mm 的较短路径，尚未达标时使用完整候选中净空不足量最小者。
- 没有完整候选时，允许围绕冻结初值继续尝试，不因四个初值失败就宣称整个区域不可行。
- 沿各开放坐标的正/负方向产生 poll 候选，初始步长 5 mm；方向列表、正负顺序和轮询游标在配置中冻结。前驱两坐标与关键段两坐标都必须能够访问，不能只改变原关键段第一坐标。
- 同时允许在保持 x 不变时切换 v1/v2 作为离散 poll；零参考仅保留规范表示，避免重复消耗。
- 步长阶梯为 5、2.5、1.25 mm。完成一次无改善轮询或当前半径全部去重后可降低半径，未完成整轮时如预算耗尽，记录 truncated，不称为收敛。
- 对搜索生成的越界参数，可采用显式的逐区间圆盘投影作为搜索提案机制。保存投影前后参数；不得改变实际运行中的系数、锚点或安全约束。也可以选择拒绝越界提案，但整轮统一。
- 参考预检失败消耗一个评价槽，不用另一候选填补该槽。
- 通过精确内容键去重；缓存命中不再产生新名义预测、不算新的独立样本。另报提案生成次数和缓存命中。
- 每任务参数提案生成尝试另设 128 次上限，防止预算外无限去重循环；耗尽即停止。

先单测冻结生成序列，正式任务前锁定实现和配置。不同任务允许按照观察到的预测质量自适应选择下一参数，这是规划算法，不是 TEST 调参；禁止在看完最终 actual 后修改算法并覆盖同一测试。

### 6.3 预算与停止

每任务总评价槽数 <=12，包括四初值、参考预检失败与预测执行失败。已消费失败槽不得重试补额。两偏好不是各十二槽，全部共用一个上限。

提前停止条件：无新合法未评价候选、最小步长轮询结束、参数生成上限到达或明确的不可继续工具错误。完整日志记录原因。

`BUDGET_EXHAUSTED_WITH_INCUMBENT` 只表示返回预算内目前最好的已评估结果。不得写 `GLOBAL_OPTIMUM`，不得承诺任何维度都充分搜索。

### 6.4 证明实际做了连续优化

用单测证明所有声明变量可进入提案；正式运行报告“非初值/非历史七模式”的提案和被实际评价数量。

如果最优最终仍是初值，照实返回；不能强制选择较差新点来制造优化效果。若全部新连续点被预检拒绝，允许研究完成，但标记 `CONTINUOUS_EVALUATION_NOT_REACHED`，不能宣称实际优化收益。

## 7. 名义候选评价与最终 actual 的边界

### 7.1 内部候选必须通过原控制链预测

每个候选从完全相同的 Task 初始物理状态及控制器历史开始，使用新的/彻底复位的私有 MjData、控制器、参考积分状态和 QP 热启动缓存，运行原 ctrl + mj_step 27 s 或直到原守卫拒绝。

允许候选内部按原算法热启动，不允许一个候选末态或 ADMM 缓存泄漏给下一个候选。

不通过固定底座 FK、末端几何或低频简化模型替代完整名义控制预测。目标与自由基座正常按仿真时间演化。模型与执行证书仍绑定各自私有候选状态。

这仍是真实控制器在私有名义环境中的物理仿真工作，不得因为叫 prediction 就漏计其成本。

### 7.2 搜索阶段证据等级

保留候选的全部在线安全/执行门禁和必要状态；计算 Task、I_support、L_full 和相关路线对净空。

搜索阶段可以复用状态直接评价，不必为每个候选再独立执行一遍完整力矩重放。其独立全身/区间验收若未实施，明确为 `NOT_RUN_SEARCH_SCREENING`。不得将“预测完整且在线守卫通过”改成正式独立全身安全通过。

现有 helper 若自动执行独立 replay 和全身验证，允许：

- 直接复用，并完整计费；或
- 添加明确的 search-screening 入口，保持原在线控制和守卫不变，独立验证状态显式未运行。

不得修改旧默认验证逻辑，把可选验证关闭偷偷带到最终 actual。最终选中参考必须重新执行并完整独立验证。

### 7.3 冻结选择后再进行最终 actual

每任务的候选搜索完成后写 `selection.json`：两偏好选中 plan、来源候选、所有质量与预算。此后不能读取 actual 结果再改选择。

actual 使用新的环境与控制器，从 Task 初态计算反馈力矩，不能播放选中候选的保存力矩，不将预测状态拷贝成 actual 轨迹，也不复用预测物理步算 actual 成功。

同一任务不同方法选择完全相同的 plan/config/identity 时，可以只执行一次并建立多方法别名，但逻辑方法分母不减少；唯一实际运行计数不得翻倍。

若 actual 与预测不一致：记录 mismatch，不强行对齐状态。正式运行后不改安全容差。无允许的误差原因时，不将该候选标记成功。

## 8. 固定的新任务协议

### 8.1 数量与生成

两个新母场景，每个只改变同一个路线球的左右位置，构成四个新任务。母场景必须与旧 B.2/B.3/B.3.1 开发母场景不同。

建议种子规则：`2026100701 + 104729 * mother_index`，mother_index=0,1。运行前以母任务 source identity 核对未与旧开发重复。若身份重复，只允许在协议冻结前按预先说明的 next-unused 规则选择；不得根据是否成功选择种子。

本轮四任务统一选 55 mm 横向球心偏移，半径保持原 25 mm，依据基础参考关键段中点与原世界横向基定位。选择 55 mm 是利用旧开发观察制定的新协议，不意味着已证明四个新任务均能达到 30 mm。

初态、目标运动、任务锚点、姿态、时限、其他障碍与母场景一致；同母成对任务除场景身份和指定球心外逐值相同。

### 8.2 不筛选失败

在候选生成前执行原初态与锚点预检。预检失败保留为任务结果，各方法仍计入四任务分母；不移动障碍、不替换任务、不扩大时限。

四个任务属于新冻结规划评估，不是训练集。本轮没有训练，也不把按任务进行的优化搜索错误称为“使用测试数据训练”。

不得读取最终 actual、未来真实状态、参考答案标签或新任务的离线最优表决定提案。私有名义预测是算法公开允许的模型计算，所有方法成本和权限制别须说明。

### 8.3 基线

每任务四个逻辑方法：

- Z0：零残差原 Cartesian 参考；
- G0：冻结几何规则 v2，关键区间远离路线球 12 mm，前驱零；
- OI：偏好 A 的连续优化结果；
- OC：偏好 B 的连续优化结果。

Z0/G0 与候选初值预测可共享缓存，但最终 baseline actual 也要从初态独立运行。Z0/G0 不拥有额外搜索预算，比较时不能隐瞒优化器更多的模型调用；这里只研究效果—成本权衡，不作 equal-compute 优势声明。

若 OC 无达到 30 mm 的计划，保留其逻辑槽，`NO_PLAN`、0 actual 步；不隐式改成 G0 后计成功。Z0/G0/OI 的 actual 都同时计算是否达到 30 mm，但它们没有因未达到这个额外偏好而改变原 Task 通过状态。

## 9. 最终 actual 的完整验收

完整 actual 应是 13,500 个原生物理步、27 s，保留含初态与规划边界的原记录。浮点时钟比较沿用原规则，不以扩大终止容差接受少一步。

每条最终 actual（包括失败前缀）必须保留：

- 原 Task 要求、姿态、窗口和终态判定；
- 实际消费参考 family/definition/plan/z 绑定；
- 原动作证书、制动、斜坡和微状态守卫；
- 保存力矩独立 replay 与状态一致性；
- 独立区间行重算；
- 原 robot-target 500 Hz 几何与声明 whole-body 50 Hz/subdivisions4；
- 相关连续体—指定路线球的新增质量净空；
- fresh 时间对齐的路径、基座漂移和命令修正向量；
- 预测与 actual 的任务状态、I_support、L_full、d_support 对照。

复用原碰撞 pair 和豁免，不把 30 mm 加到刚性接触末端任务对。不把 whole-body50Hz/sub4 写成全500Hz或连续时间安全。

失败后不执行下一步的事实需要保存；停止仿真不是硬件安全备份。拒绝之后缺失指标写 `NOT_RUN`/null，不拿较短 prefix 获得更短路线成绩。

退出码要区分工具执行错误与研究负结果：命令保存完整结果后 exit0 可以存在，同时 Task=false 或 Preference=false；工具失败非零。总报告读取真实状态，不以 exit0 推断机器人成功。

## 10. 质量对比与最终判断

### 10.1 四张核心表

1. 任务/方法状态：每组分母4，预检拒绝、NO_PLAN、actual进入数、27s完整任务成功、原独立门禁、30mm偏好是否达到。

4. 搜索贡献：四个初值的有限最优、整个连续搜索的严格最优、tie-selected、实际输出、新点改进量与预算位置。

完整质量只在双方同任务均完整成功时配对比较，必须并列显示两组全4任务的成功率。样本缺失不填入任意惩罚常数构造均值；若需要预算内失败排序，用明确类别状态，不能把失败prefix长度当目标值。

### 10.2 新成果如何命名

- OI 未改进或选中原初值：有可调用的有限规划器，不声明优化优越。
- 只在预测中改善、actual未确认：预测改善，实际收益未建立。

- OC以较大路径换净空：报告取舍，不声称 Pareto 支配。
- 连续搜索找到较好点：归因于本轮非学习搜索，不记作 Diffusion 成功。
- 所有组相近：保留 Z0/G0，不追加预算。

原10%门槛只在其原定义/窗口的历史结论中保留。本轮不得用新增 I_support 去重算并改判旧B.3成功；也不要求每个新任务都必须得到正收益才能关闭研究。

## 12. 必需单测与门禁

优先使用 mock evaluator 验证搜索和账本，避免用27s物理试验代替单测。

### 12.1 表示与身份

### 12.2 搜索机制

- 至少构造可证明不属于四初值/七模式的新连续候选；
- 每个活跃坐标可被访问；
- A/B共享十二槽；参考拒绝消耗槽；缓存不积分；重复不能无限循环；

- 同任务独立候选起点和控制器缓存一致，无候选间状态污染。

### 12.3 偏好与评价

- I_support/旧I_key/I_full分开，10D/7D平方RMS恒等式；
- tie组锚定strict minimum，不作链式并列；
- 30mm为偏好不是安全配置；29.999mm不得因安全容差通过；
- below30完整safe候选可以作为搜索中心但不能自动成为OC输出；
- 缺失净空不默认为0或安全；related pair不被全局最小替换；
- 失败prefix成本不击败完整合格候选；
- 未消费拒绝行与已消费非有限量分别处理；
- 工具exit0和Task/Preference结果解耦。

### 12.4 最终运行顺序

先冻结所有新任务和算法，完成四任务的搜索并封存全部 selection，再进入最终 actual。actual 阶段优先执行首任务 Z0，作为新流程的正例/失败证据，该次计入16槽，不另加 smoke 完整运行；该 actual 结果不得回流改变搜索、参数或剩余 selection。

若它失败，保留原因，不换一个更容易任务。只有确认是实现/基础设施错误时才暂停、记录新 producer 与恢复方案，不覆盖或重新计分原槽位；单纯 Task/执行拒绝不能触发额外重试。其余任务按已冻结计划继续，不能悄悄筛选。
