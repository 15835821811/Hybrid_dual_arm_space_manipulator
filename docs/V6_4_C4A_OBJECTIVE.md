## 2. 阶段 A：Diffusion 架构审计

首先只开展源码、数据和数值审计，不启动新物理仿真。

### A.1 数学和实现一致性

审计并使用单元测试验证：

- 12D 残差和最多 4D 有效搜索变量的映射是否正确。
- v-prediction 的训练目标、反推公式是否数学一致。
- Cosine100、DDIM20 的时间步、噪声调度与边界处理是否正确。
- inactive mask 是否在训练、加噪、去噪和反归一化各阶段严格生效。
- 相同 Task、checkpoint、噪声和运行配置能否确定性复现。
- Raw 提案是否满足有限数值、非活动坐标为零及每区间 20 mm 范数约束。
- 不合法提案是否保持原样拒绝，不发生静默 clamp、projection、补抽或替换。
- 条件预处理是否仅使用 TRAIN 拟合的 scaler。
- 模型输出是否只具有高层初值提案权限，不影响底层控制器及安全门禁。

输出每项检查的 PASS/FAIL/BLOCKED、最小复现实例和证据路径。

### A.2 模型与数据适配性

检查：

- 896 维条件向量的字段构成、有效变化维数、常量、缺失值与高度相关特征。
- TRAIN/VAL/TEST 是否真正按母场景身份隔离。
- 55 个唯一监督标签的来源、去重身份和 A/B、v1/v2 覆盖。
- 具有 route-quality 与 initializer-effect 监督来源的有效样本数量及重叠。
- Diffusion 的 152332 个参数与实际独立训练母场景数量是否相匹配。
- 对比 S8 的模型容量、数据、训练预算及推理开销是否公平。
- 固定单次 DDIM 提案是否能够反映所学分布的多样性。
- 当前数据是否有多个分离的合格路线模式；没有证据时不得声称模型已经学到多模态分布。

可以在 TRAIN 或既有 VAL 条件上开展固定种子的离线采样诊断，记录 raw 合法性、有效幅值、不同采样间距离、与训练标签的距离及条件敏感性。

这些采样仅作模型诊断，不经过物理执行，不得用于重新选择 C.3 checkpoint。

禁止用已有 TEST 反复试噪声并挑选有利结果。

最终判断当前架构属于：

- `ARCHITECTURE_SUITABLE`
- `ARCHITECTURE_CONDITIONALLY_SUITABLE`
- `ARCHITECTURE_NOT_JUSTIFIED`
- `INSUFFICIENT_EVIDENCE`

给出技术理由及证据边界。

## 3. 阶段 B：C.3 搜索失败的法证分析

利用全部已经封存的 C.3 候选日志，不重新运行已有 TEST。

重点检验以下事实与假设：

**已观察事实：**

- R8 在全部四个 TEST Task 的第 4 个候选评价槽首次找到 B30 名义合格候选。
- D8 将规则初值槽 1 和槽 3 替换为 Diffusion 提案。
- D8 的 Preference B 最终只有 1/4 完整任务通过。
- D8 在 `c3_test0_plus` 的两个 raw 提案合法，但 B 仍然 NO_PLAN。

**待验证假设：**

H1：移除几何规则 B/v2 20 mm 初值损失了重要的可行路线覆盖。

H2：Diffusion 生成结果在 B 的局部净空指标上系统性不足。

H3：后续局部轮询受到较差搜索中心的影响，无法在八槽内恢复合格路线。

H4：有限监督数据与单次固定采样不足以表示不同绕行模式。

H5：模型或归一化、掩码、DDIM 实现存在数值缺陷。

逐 Task、逐 Endpoint 和逐 A/B 分析：

- 四个初始候选的 source、family、raw z、合法性、拒绝原因。
- 候选几何与名义预测结果。
- `I_support`、`L_full`、`d_support`。
- 首次完整合格、首次 B30、首次近 R12 质量命中的槽号。
- A/B 最终选择与 `NO_PLAN`。
- 最终选中候选是否来自直接学习初值、学习后代或共同规则种子。
- 实际执行的完整任务、五项门禁结果。
- 预测成本、物理积分步数、几何查询数、冷启动成本。
- 合法重复缓存、raw 拒绝、未执行状态。

必须区分确定事实、相关性与因果假设。不得仅根据最终候选谱系声称某种初值具有因果必要性。

输出一个可机器读取的诊断矩阵，以及重点 B 失败案例的完整证据链。

## 4. 阶段 C：最小接入策略改进

只有在阶段 A/B 完成、核心数值测试通过且原因分析明确后，才允许新增 C4-A 实验策略。

不要修改 Diffusion 网络结构，也不要训练新权重。

设计并实现三个可严格区分的方案：

**P0：Rule8**

保留 C.3 原 R8 搜索，作为对照。

**P1：Diffusion8-Replacement**

保留 C.3 原 D8 接入，即槽 1/3 被 Diffusion A/B 替换。

**P2：Diffusion8-Rule-Preserving Portfolio**

新建可选接入策略，预定义为：

- 槽 0–3：保留全部四个原规则初值。
- 槽 4：插入冻结的 Diffusion A/v1 提案。
- 槽 5：插入冻结的 Diffusion B/v2 提案。
- 槽 6–7：复用 C.1 原连续轮询与候选排序逻辑。
- 总候选评价预算仍为 8。
- A/B 共享同一搜索池。
- 仍然只允许两次冻结 Diffusion 提案。
- 严格计入生成、检验、重复、拒绝与物理预测成本。

这是一个有待验证的候选保留策略，不得预设一定优于 P0/P1，也不得声称其保留四个规则种子就能保证最终 Actual 不退化。

如果需要扩展原搜索器的 seed schedule 接口，必须通过可选参数或独立 C4 适配层实现，并增加回归测试，证明不启用 C4 时原 C.3 的输出与排序完全不变。

所有新的 raw 提案仍由原参数合同验证；不得新增隐式修复、无预算 fallback 或额外物理调用。

P2 只用于诊断“学习提案是替换规则候选更合适，还是作为补充候选更合适”。

不得根据某个方法是否成功来重抽或替换任务。

先执行静态和 mock 审计，再执行真实预算受控物理实验。

本轮最高预算：

- 2 个 DEV Task。
- 3 个策略：P0、P1、P2。
- 每策略每 Task 最多 8 个候选槽。
- 总候选槽不超过 48。
- 最终 A/B logical Actual 不超过 12 个。
- 不新增 Diffusion 训练更新。
- 不修改 C.3 正式 TEST 或 VAL。

## 6. 科学判断及下一阶段门禁

比较 P0、P1、P2，必须先评价任务能力与安全验收，再评价轨迹质量，最后评价规划成本。

- 如果 S8/N8 用相同 Portfolio 接入也可能获得收益，下一阶段应如何公平比较？
- 当前主要瓶颈究竟属于模型、数据、初值接入还是路线表示？
- 是否有足够证据进入更复杂的多障碍、多模态路线规划基准？

C4-A 只有两个 DEV Task，因此即使 P2 优于 P1，也只能将其描述为局部先导结果，不能宣称统计泛化或总体神经收益。

最终输出明确的 `GO / MODIFY / NO_GO` 决策：

- `GO`：初步证据支持继续评估 Diffusion，进入独立的 C4-B 扩展实验设计。
- `MODIFY`：架构方向可保留，但必须先解决数据、输出质量或搜索接口问题。
- `NO_GO`：目前没有足够理由继续扩大 Diffusion 训练或模型规模，保留 C.1 规则方法。

不能为获得 GO 而提高实验预算、变更 TEST、弱化对照方法或改变安全阈值。
