所有阶段的 RRT 和 SQP 调用均为 0。main/DEV 的真实 rollout、mj_step 均为 0。
FK 指显式 scratch `mj_kinematics`；forward 指显式 `mj_forward`，涵盖跟踪、
重放和原生状态验证。引擎内部的运动学计算不重复计作 Python API 调用。
因此物理审计的 scratch FK=0 并不表示物理阶段没有运动学计算。

训练/VAL 网络调用 400 次，重载检查另 2 次；DEV 推理网络调用共 640 次
（40 个 Diffusion 候选各 16 次 DDIM）。引导全路径代价：结构化基线 875 次，
去噪内引导 800 次，无引导 0 次。两种引导方法各 20 候选×2 次更新，
每次 8 个方向×正负扰动=16 次中心差分代价；基础、半步检查和试探另计。
结构化方法的额外试探次数是实际工作量，不被“相同更新预算”掩盖。

## 首轮、回归重复与存储

`smoke_001` 是修复发布完整性、资源计数和显式 study 恢复控制前的首次 smoke。
它的实际执行源码已归档于 `ff_prior/evidence/smoke_001/executed_source.zip`。
最终源码为 `smoke_002` 的归档版本，两个运行均保留，未覆盖旧输出。

两轮合计 800 次提案、798 条有效记录，但仅 **399 个不同 reference_hash**；
399 条有效参考全部重复出现，不能计为 798 条独立数据。两轮共 50 次真实执行、
50 次全轨迹独立重放，最终运行贡献其中 25+25。

两轮已测阶段 wall 合计 922.336922 秒，训练另 14.914423 秒；
阶段 CPU 合计 907.312500 秒，训练另 19.296875 秒。
首轮没有单列 dataset 阶段及显式 mj_forward 计数，记为未测，不能补写为 0。
首次实现过程、预检和测试的开销没有完整全程剖析，不能宣称总开发成本已穷尽。

发布打包时本地完整运行存储：首轮 1,397,730,716 字节，最终轮 1,397,842,715
字节，合计约 2.796 GB（十进制）；均留在 `artifacts/v7_1/`，未提交或上传。
紧凑最终证据约 5.3 MB，含报告、原始计划记录、一个完整 ctrl 序列与 101 个
原生状态检查点、一个参考样本及图片/代表视频，不含模型 checkpoint 或全量数据。
精确文件大小和 SHA256 见 `evidence_manifest.json`。

额外可携带样本工具针对同一条轨迹共运行 3 次、15750 步：初版遗漏记录前的
forward 计算而在比较处 FAIL；对齐时序后 PASS（112.682098 wall 秒、112.015625
CPU 秒），随后避免逐步重复解压 ctrl 的版本再次 PASS（6.577140 wall 秒、
6.468750 CPU 秒）。第一次未保存耗时，明确为 unknown。这是工具工程验证，
不是新增执行样本，不增加上面的 25/50 成功计数；详见 portable_replay_history.json。

## 验证范围

所有结果仅适用于冻结固定初态、零初始动量、静态场景、当前模型及非穿透 profile。
主生成无附加外部障碍；原模型目标卫星仍参与全机检查。
静态球/OBB SceneSpec 与反例有软件/几何测试，不据此宣称障碍规划成功率。
几何是加密离散审计，不是连续时间证明。参考力矩可行性 NOT_EVALUATED，
仅真实执行子集具有力矩证据。任意初态、动态障碍、硬件均 NOT_VALIDATED。
pilot、study、严格多模态物理实验和最终 TEST 均 NOT_RUN。
