## 3. 接口合同与可自动验证的职责

### 3.1 公共接口

```python
plan(initial_state, task_spec, scene_spec, planning_budget) -> PlanningResult
validate(candidate, initial_state, task_spec, scene_spec, profile) -> ValidationReport
execute(selected_plan, physical_snapshot, controller_memory, profile) -> ExecutionReport
replay(execution_bundle, profile) -> ReplayReport
```

输入初态与任务一经进入`plan`即只读。`plan`不得读取任务对应的专家路径；`validate`不得生成新控制点；`execute`不得根据航点编号自行重建另一条路径。

### 3.2 必需合同

- **RobotSpec**：源与编译模型哈希、版本、关节/执行器名称、自由基座与卫星索引、17→67映射及偏置、全部限位、质量/惯量、armature/damping、碰撞拓扑、单位和坐标顺序。
- **InitialState**：完整原生积分快照、绝对时间、机器人和卫星状态、实际67维关节量、17维表示及其流形残差、控制记忆、已知外力、测量来源。当前快照可能是836维，但代码通过状态接口查询长度并核对，禁止把836当自由度或普适常量。[S4]
- **TaskSpec**：末端身份、世界目标/中间航点/保持或追踪区间、时间戳或窗口、位姿掩码、允许误差、任务时长、终端导数策略。显式区分“指定时刻到达”“区间保持”“区间持续追踪”。
- **SceneSpec**：障碍形状、尺寸、位姿、运动预测、目标实体几何、碰撞对策略及坐标系；改变文件名/对象排列不得改变物理规划含义。
- **PlanningBudget**：候选数、准确DDIM步数、引导步段、每步更新/线搜索上限、传播网格策略、时间/查询/内存上限、种子。禁止暗中追加候选。
- **PlanningResult**：每个候选的seed、采样与配置身份、控制点、q/qd/qdd、基座预测、目标误差、几何/力矩信息、验证报告、选择理由、失败原因。全失败时返回`NO_VALID_CANDIDATE`，不伪造选择结果。

### 3.3 必须先写出的架构测试

- **ARCH-01**：主入口运行时将历史搜索、整轨迹恢复及bypass入口替换为“被调用即报错”的哨兵，完整规划仍可运行。静态import扫描和运行时调用追踪同时做。
- **ARCH-02**：验收前后候选控制点、时间参数、初态及任务哈希完全不变。
- **ARCH-03**：在预设活跃约束样例中，至少两个非最后的采样步确实调用完整引导；修正后的状态被后续网络调用消费。不是只记录一个`guidance=True`字段。
- **ARCH-04**：相同x_t/条件/时间步下，启用/关闭引导的后续状态不同；目标/障碍可控扰动会改变对应引导项；关闭某一项只关闭引导，不关闭最终验收。
- **ARCH-05**：每个冷启动候选来自记录的新噪声与当前任务，网络实际调用数等于请求步数；没有历史轨迹加载。确定性DDIM允许，但候选初始噪声不同。
- **ARCH-06**：模型权重干预、条件置乱、无学习对照能改变相应输出。这里是机制/依赖测试，不把“输出不同”当作学习优势。
- **ARCH-07**：不注入终端关节答案；世界目标任务中终端构型仍可调整。隐藏可行解证书不属于PlannerInputs。
- **ARCH-08**：不同航点数量、文件名、对象顺序使用同一个solver。核心不能按W6/W7、R1/C4、54.5秒等标识分支。
- **ARCH-09**：主要规划统计包括所有候选、失败和预算，不允许只保留选中成功轨迹。
- **ARCH-10**：关闭安全修正的规划验收与安全辅助执行分别报告；不为了论文关闭真实执行所需的安全保护。

哨兵及统计既覆盖显式函数调用，也检查加载的文件、动态导入和实际方法身份；允许白名单里的机器人参数/几何资源读取。

## 4. 数学与物理实现要求

### 4.1 样条、边界与单位

三次B样条是默认表示。原型采用24个控制点、17个规划坐标；对静止起步与静止终端导数采用独立约束消元后，可以保留19×17=323个自由标量。更一般的边界类型按实际秩计算自由维度，不硬编码323。

```text
A_bc C = b_bc
C = C_bc + N Z
q(t)   = B0(t; T, knots) C
qd(t)  = B1(t; T, knots) C
qdd(t) = B2(t; T, knots) C
```

要求`A_bc @ N=0`；各关节边界不同时先展平C再构建线性系统，不能假设所有关节共用同一零空间维数。固定秩边界模板使用确定性QR/SVD基或显式局部消元，避免样本间零空间基符号/排序变化导致训练标签不连续。所有训练、采样、验收、执行用同一个解码合同。检验1/T与1/T²的时间缩放。

初态、末态的构型/导数要求按任务分别指定。目标追踪段不能默认终端速度为零；不能同时硬固定未知终端构型和两个任意世界位姿。中间航点是任务约束，不是硬塞入一个已知逆解。

非零初态时区分实际状态、参考边界与控制记忆：它们可能存在跟踪误差，不能强行要求完全相等，更不能写实际状态使其相等。拼接参考保持规定的C1/C2连续性；起始物理误差进入传播误差预算。超过已验证适用域则拒绝该约化预测或使用显式升级的预测模式，不静默投影。

完整自由空间生成，禁止TRAIN-SVD低秩截断后把剩余自由度全部交给后处理。只允许可逆尺度变换和解析边界降维。先固定时长；变时长/节点数属于显式配置或后续版本，冻结任务的时限不能无限延长。

### 4.2 一个物理模型，两种实现角色

**原生参照**：保留原机器人实际参数和MuJoCo模型，执行与精确几何验证采用该模型。不同算子使用独立scratch data，不接触正在执行的实际状态。

**可微规划后端**：从同一个可追溯RobotSpec建立，首先以float64实现可微FK、质量/惯性、基座传播和名义逆动力学；网络可float32。可以用批处理、缓存不变拓扑、checkpointing和向量化加速，但不能detach状态相关质量矩阵或用常数雅可比假装自由漂浮。

可以实现有解析/校验VJP的自定义算子；把NumPy/MuJoCo结果转成tensor本身不等于可微。全323变量中心差分适用于小样例正确性检查，不作为主采样循环的长期生产后端。

### 4.3 零动量原型与一般动量能力

限定的零初始动量、无机器人外力情形可使用：

```text
v_a = B_map qd
v_b = - solve(M_bb, M_ba v_a)
```

必须传播真实基座位姿，再计算世界坐标末端、全部机体和几何。此公式不能用于任意非零速度继承状态而不检查动量。只把重力设为零，不算完成自由漂浮建模。

一般初态建议使用一致世界参考点O下的物理动量映射：

```text
H_O^W = A_b^W(x) v_b + A_a^W(x) v_a
v_b = solve(A_b^W, H_O^W - A_a^W v_a)
```

`H_O^W`由真实初态物理体量确定，按声明外力/力矩积分更新。必须推导清楚基座速度是世界平移/机体系角速度还是另一约定；角动量参考点不能在不同阶段默默改变。A、M和它们的导数一致性通过独立检查证明，而不是只把旧`M@v`基座切片改个名字。

物理机器人不包含独立目标卫星；卫星外推力不能拿来抵消机器人动量。若有额外转子或等效惯性，明确其物理范围与仿真模型语义，不能忽略后又宣称全系统守恒。

默认主任务不允许机器人外部推进器和接触捕获。卫星是独立自由刚体，其公开受力或初始运动分别记录。初始卫星非零速度可作为独立任务合法初态，但不能在连续链中未经声明突然注入。

### 4.4 积分、误差与整路径灵敏度

先实现一个与现有参照可比较的二阶流形一致传播，使用四元数/旋转群的合法更新，再依据误差—成本实测决定是否升级积分器或网格。采用RK4不等于动量问题自动解决；MuJoCo 3.3.2的`mjd_transitionFD`/`mjd_inverseFD`对RK4有限制，不能同时把两者作为未经验证的组合依赖。[S4]

离散计算图应保留：

```text
x[j+1] = F(x[j], q[j], qd[j], dt)
dx[j+1]/dZ = F_x dx[j]/dZ + F_(q,qd) d(q,qd)[j]/dZ
```

世界任务/距离梯度必须包含先前路径造成的基座累积变化，不能以瞬时广义雅可比替代整路径导数。瞬时广义雅可比可作为单步对照，不得成为冻结基座的漏洞。

非零动量、时变目标或外力时按真实时间传播，不使用静态零动量的相位重定时缓存。缓存键包括模型、初态、轨迹、时间、场景、积分与几何策略版本；禁止跨场景或跨初态借用缓存。

### 4.5 连续体模型与67维实际状态

以当前离散链和质量分布为物理权威。解析PCC可作几何代理，但不能不校验就替换离散动力学；不得把几何曲率诊断称为材料应变/连续体弹性动力学。

实际执行保留67维，不把它强制改成`B_map q`。记录q67与规划流形、速度流形之间的残差。动态接续采用约化预测时必须校准并冻结可接受残差域，检查初始预测基座速度与实际值的差；误差计入几何与任务裕量。若该近似不能通过执行对照，应在同一模块中升级为可微67维伺服预测或其他明确建模方式，不剪裁实际状态。

### 4.6 多空间执行器需求

首版针对实际67路直接关节力矩模型，不虚构绳索张力模型。令h为与原生模型一致的偏置力减被动力，名义无机器人外力/无接触时：

```text
a_a   = B_map qdd
a_b   = - solve(M_bb, M_ba a_a + h_b)
tau_a = M_ab a_b + M_aa a_a + h_a
```

在传播所得状态与速度上计算，纳入实际armature/damping、齿轮比和执行器限值语义。检查未驱动基座方程残差，核对`mj_inverse`和独立前向响应。若传播求得的基座加速度与该动力学分块不相容，修复模型/坐标/积分，而不是仅把tau变小。

代价约束67路原始名义力矩及q/qd/qdd，并为反馈需求预留校准裕量。真实执行额外检查原始力矩、饱和比例及跟踪误差；规划前馈通过不等于闭环通过。参数B_map仅是关节映射，不是论文绳索雅可比。真实传动模型以后作为独立ActuatorModel扩展，不阻塞首版正确的关节力矩规划。

### 4.7 世界物理动量合同

分别累计机器人本体的世界线动量和固定世界参考点O的角动量：

```text
P = sum_i m_i v_com_i
L_O = sum_i (R_i I_i R_i.T omega_i + (r_com_i - O) × m_i v_com_i)
R_P(t) = P(t) - P(0) - integral F_ext dt
R_L(t) = L_O(t) - L_O(0) - integral tau_ext_about_O dt
```

以上为本体模型定义；存在额外物理储能/动量部件时按模型明确扩展。`M(q)v`的基座分量可保留诊断，但不能直接等同上述世界角动量。

先依据任务精度、时域和物理量意义规定允许的数值误差上界，再在独立校准轨迹上做dt、dt/2、dt/4及不同幅度/静止/非零初始动量检查。不能仅把当前残差最大值加一个余量就定义为通过阈值。冻结物理数值误差预算、全程积分窗口和参考尺度后，再进入正式任务。旧“每段交换量决定阈值”的记录可保留历史对照，但不用于新段动态追认。全链残差从真实根初态累计，同时报告分段增量；不能每段重置残差账本掩盖累计漂移。

新合同是新版本，只作用于新run；原快照动量失败保持失败。若误差无法满足预先定义的容许物理精度，应改数值实现或公开受限适用域，不凭同一失败样本反向放宽阈值。

## 5. 全机几何与可微代价

### 5.1 两层几何，同一机器人身份

引导层采用可批处理的有限体积几何（胶囊/球/盒/凸体，或经校准的距离场），覆盖连续体全身、刚性臂所有连杆、安装结构、基座及目标实体。不得退化成末端点或裸中心线检查。保留显式拓扑排除，不新增“为了通过”而隐藏的碰撞豁免；首版不包含接触抓捕许可。

最终验收层使用原生实体几何和独立稠密/自适应时间网格。引导代理通过不意味着原生几何通过。

优先采用可解释的包络构造，并检查代理覆盖原几何。不能严格证明覆盖时，保存测量误差与适用域，明确称经验代理；独立原生检查继续作为硬门，不能用有限随机测试声称全域严格包络。

初期每个场景保留全部合法对的catalog；可用保守下界筛除远对。近对激活集每次迭代重建，不能永久冻结开始时选出的少量对。分开“筛除下界”“截断距离”“精确距离”；截断值不得冒充真实距离。

### 5.2 能量与归一化

首版冻结五项：

```text
E = w_task E_task + w_collision E_collision
  + w_joint E_joint + w_actuator E_actuator + w_smooth E_smooth
```

- 任务项：双末端位置按任务位置容差归一化；SO(3)误差按姿态容差归一化；按任务掩码启用；区间追踪还按时间积分。不要把米和弧度直接混成未归一化范数。
- 几何项：基于传播后的全机世界距离，使用安全缓冲内的平滑hinge等可解释惩罚；自碰撞、臂间、基座、目标与外障碍均按相同pair policy处理。
- 关节项：同时检查17维工作域、67维实际映射范围、解析速度和加速度。凸包/导数控制系数界可作为高效保守检查。
- 执行器项：67路名义原始力矩超限与预留裕量；只有模型确实支持时才加入功率、力矩变化率、绳索/电机限值，不能编造规格。
- 平滑项：物理时间下的积分平方加速度；三次样条不自动保证jerk连续，若记录jerk应说明节点处分段性质。

用时间积分或对时域归一的平均、配合峰值项，避免增加网格数就改变权重含义。批量梯度按样本计算，不让增加候选数无意改变单候选步长。记录原始、尺度化、裁剪和加权后的分项梯度；不把逐项单位化的合成方向声称为原标量总能量的精确梯度。

默认先采用一个清楚的无量纲总能量和统一更新范数限制。只有证据表明冲突严重，才版本化增加分层策略；不能同时上线多套复杂引导策略后无法归因。

### 5.3 中间违规不等于立即放弃候选

采样中间状态可能越限或碰撞。只要有限且位于数值后端支持域，应计算真实惩罚和下降方向，不像执行层那样一发现penetration就终止。penetrating witness、重合中心、SO(3)接近π、最近特征切换必须有明确处理/失败标签。

不得用“碰撞时返回常数很大代价但零梯度”冒充可修复引导。不得遇到一项初始化失败就静默跳过。数值不支持时，该候选以具体错误退出分母；不转调用旧修复器。

精确碰撞距离的自定义梯度可由见证点和几何雅可比构造，但需检查符号、交换geom顺序、法向坐标及穿透区适用性；若无稳定穿透梯度，使用经过验证、可在穿透区计算的引导代理，原生几何负责最后拒绝。

### 5.4 时间采样与裕量

引导网格包含初末时刻、所有指定航点时刻、任务区间边界和必要的样条节点；不能只取均匀点漏掉约束时刻。最终验收独立加密，检查几何平移和转动的空间影响，而不是只检查关节增量。

暂用旧合同的非穿透、双臂5mm/1°和2mm几何细化上限作为继承验收基线；正式使用前从实际合同确认。不能复制参考论文的20mm中心线阈值作为你模型的实体表面距离门。

规划缓冲与硬验收分开：规划缓冲至少覆盖已校准的代理误差、传播误差、实际跟踪偏差和数值余量。经验测得的包络不等于严格误差界。初期可以在配置中试用2mm等缓冲，但这是DEV设计参数，不是新硬件安全保证；正式任务前冻结最终profile。

## 6. 条件扩散与真正的去噪内引导

### 6.1 首版模型定型

采用完整自由控制变量token的条件Transformer，建议起点：hidden=256、4层、8头、MLP ratio=4、无dropout或固定小值，使用实际实现的条件调制/交叉注意力。条件包含可用初态特征、任务约束token、时间/掩码、时长和边界类型。旋转采用连续编码，最终误差以SO(3)评估。

首版不要求网络直接编码障碍；障碍通过推理期引导进入，符合先验与场景求解分工。不得因此跳过场景梯度；改变场景时裸网络相同不构成错误，完整引导后的轨迹应响应场景。

不输入合成时的终端关节种子、未来真实卫星轨迹、历史成功路径或证书控制点。可先固定世界坐标；若用初始基座坐标作统一规范化，必须同时变换初态、目标、障碍、动量和输出，且此坐标系在时域内固定，不能跟随当前基座移动而偷换任务。

初版保留v-prediction以避免无意义的预测类型迁移：1000步固定噪声计划，准确60次DDIM调用，eta=0；每任务至少5个独立噪声候选。5是总候选数，不是假设5个都可行，不足5个成功不得循环补种子到通过。

60步、最后18步引导仅为借鉴手稿的开发初值；不得照抄0.1步长到不同归一化物理空间而不校准。正式参数由DEV确定、VAL冻结后选定。后续增大候选数或步数只能作为版本化预算实验，所有方法的比较口径同步。

### 6.2 首选采样数学约定

在归一化自由变量x上扩散，网络输出v。用a=sqrt(alpha_bar_k)、s=sqrt(1-alpha_bar_k)：

```text
x0_hat = a*x_k - s*v_theta
noise_hat = s*x_k + a*v_theta
```

引导对clean估计求导：

```text
x0_hat → 反归一化Z → 边界解码C → 物理传播 → E
```

计算`dE/dx0_hat`，限制归一化步长与物理控制点变化幅度，得到`x0_guided`。对同一个x_k重新构造：

```text
noise_guided = (x_k - a*x0_guided) / s
x_next = sqrt(alpha_bar_next)*x0_guided
       + sqrt(1-alpha_bar_next)*noise_guided
```

最后一步`alpha_bar_next=1`，返回clean。处理小s、dtype和数值域；不要在除零位置计算噪声。更新后检查分解残差，禁止用修正前的噪声偷偷搭配修正后的clean。

这里是一个定义明确的启发式guided-DDIM，不声称精确约束后验采样。允许在每个去噪步骤边界detach网络图以节省内存，但clean→能量→控制变量这一物理图不能断。无需把整个60步网络反向传播用于推理期约束求导。

### 6.3 引导预算与更新

DEV初值：最后18个网络步骤引导，每步1次梯度更新，可有最多2次缩步试探；最多3次更新/步的扩展必须版本化。引导步骤分布在多个非末步，不能把全部预算集中在最后一步。网络与引导交替，最终输出不能再经过全任务优化。

对噪声后期严重违规候选，允许有限域保护或拒绝；禁止隐性引入目标IK、全轨迹SQP或裁剪真实执行状态。解析边界消元可以始终保持初始条件。数值域保护必须记录修改幅度、目的和适用范围，不能把裁剪后的结果说成裸网络输出。

代价不是所有反向步都必须单调下降：网络更新也会改变能量。分别记录“本次guide前后能量”和“相邻完整采样步能量”，不能事后抹平上升段。

### 6.4 每个候选保存的最小来源

```text
task/model/checkpoint/config/scaler hashes
sampling_seed, candidate_index, actual_network_calls
每个采样步：noise_level、分项能量、guidance是否激活
每次guide：梯度范数、步长、拒绝/缩步、active pair摘要
x_k、clean预测、guided clean的控制变量或可无损恢复表示
final_control_points_hash、validator_input_hash
post_sampling_trajectory_repair_calls=0
```

控制变量轨迹较小，可完整保存；不要为每个去噪步保存整个大型模型或所有质量矩阵。全机原生执行记录另存，媒体生成不重新运行物理。

## 7. 数据与训练：先验为主，不重建无限专家工程

### 7.1 数据合同

主类为`FF_MODEL_PRIOR`：从合法初态和结构化平滑运动前向生成，经独立模型检查后入库。不是每条都搜索固定目标，更不是每条都要完整力矩执行＋重放。另有明确的`EXECUTION_VERIFIED`校准子集；两者标签不互相冒充。

保留每条样本的机器人/初态/控制点/时长/边界/传播/几何/执行器模型版本。世界标签来自该条自由漂浮传播。训练合成可以先生成路径再派生目标，但冻结评测禁止这样重标。

初态只覆盖固定零速时，明确能力范围；最终运动中接续要加入物理一致的非零初态窗口，不直接随机赋一个与关节速度不相容的基座速度。不能把同一关节终点的多条路径伪装成同一世界目标的多个解。

### 7.2 样本生成

使用解析边界样条、相关扰动、两臂先后运动、不同关节组分配和多时间尺度形状。可以使用有限、公开的平滑/关节/力矩可行性精修，但不得逐环境运行重型路径搜索。避免所有样本都处于同一低秩时间子空间；检查时间协方差谱及各自由方向覆盖，既不把谱满秩当作复杂拓扑覆盖，也不把结构化先验限制死。

便宜筛选优先：有限值、边界、关节/导数界→自碰撞与实体目标→自由漂浮传播及名义力矩→标签。实际先后可按计算复用优化；所有入库样本必须具备完整世界标签依据。外障碍适应首版交给推理期，目标实体和自碰撞仍需处理。

默认规模按质量递增：32条仅作过拟合/软件调试；2,000条模型有效先验pilot；20,000条作为首轮主训练规模；根据覆盖和验证诊断再分批增到50,000或100,000，不预设越多越好。每批记录尝试数、拒绝原因和分布变化，不为了数量降低门槛。以上为任务书建议量级，不是手稿数据的复制要求。

### 7.3 任务条件与时间窗口

从前向轨迹抽取终端、少量中间位姿、不同时间约束集合，训练可变数量任务token。不要只训练“七个点”，也不要把所有稠密轨迹点作为条件，把任务变成已知路径的编码解码。

持续追踪条件可用公开目标运动参数/稀疏预测token，能量在所需密度上评价；不必对每个未来状态都输入传感器真值。非零动量轨迹即使末端关节速度为零，也不自动满足世界位姿保持，不能给它贴上固定世界hold标签。

同一原轨迹的裁窗、重定时、扰动衍生与目标邻域归入同一族；先划分，再拟合所有normalizer、特征统计或预处理。已用于调试的原七点/旧场景属于DEV，不计作未见TEST。

### 7.4 训练策略

先用标准v-MSE建立可工作先验。建议AdamW、lr=2e-4、batch按硬件自适应，固定seed与EMA策略，保存优化器、RNG、更新计数、数据manifest；不是强制固定训练时长。用32条过拟合排查表示/条件/损失错误，但该结果不进入泛化统计。

用独立VAL同时检查去噪损失、从完整噪声采样的边界/运动/任务残差和候选多样性。只看MSE下降不能进入正式结论。checkpoint选择规则在正式比较前冻结，TEST不用于选择。

先不叠加复杂世界目标训练损失、蒸馏和闭环强化学习。若先验确实不响应条件或覆盖不足，先修数据和条件，再对单一改动做独立版本实验，不以“训练补偿推理缺少引导”为借口。

## 8. 独立验收、执行与连续场景

### 8.1 验收器不修复

验收使用只读控制点及精确任务，复算q/qd/qdd、独立传播、全机几何、名义力矩及边界。可改变检查网格，不能改变控制点、时长、目标或机器人参数。需要修复时，返回失败；新生成属于新候选或新run，不能在同一candidate_id中替换答案。

模型门至少包括：身份、有限值、完整初态/边界、17与67维范围、导数、自由漂浮传播收敛、未驱动方程、全任务位姿约束、全机几何/细化、名义原始力矩、时间与保持要求。

合格候选按预先冻结的残余代价、平滑性和必要次序选择；不得根据后续实际执行结果挑成功者。全失败明确返回失败。因预算导致未检完的候选是`INCOMPLETE_VALIDATION`，不是通过。

### 8.2 执行与安全层

复用并冻结参考跟踪器，输入只来自选中计划。实际循环只通过合法控制/外力输入和原生积分更新状态；不写qpos/qvel/time制造到达、动量或碰撞通过。标明控制器原始力矩与实际饱和力矩。

安全层始终保留必要保护。普通PD反馈属于跟踪，不算替代规划；几何参考改写、任务参考重新生成或超出预设容许量的安全干预，单独标为`SAFETY_ASSISTED`。不得为了让该列为零而禁用安全层。

正式执行结果区分：`PLAN_VALID`、`EXECUTION_VERIFIED`、`SAFETY_ASSISTED_EXECUTION`、`NO_VALID_CANDIDATE`、`EXECUTION_FAILED`、`NUMERICAL_FAILURE`及`RESOURCE_INCOMPLETE`。辅助成功不替代“规划器独立产生可执行计划”的主统计。

### 8.3 独立重放与初态

使用同一完整初态，仅恢复一次，消费保存的控制与外力序列独立积分，不能逐帧复制状态。保存完整state mask、模型、数值库版本、积分器与设置、控制输入、时间、外力作用点和原始结果。

同配置确定性重放初始目标容差取原合同1e-10；若平台变化使其不适用，先在无任务校准上建立新profile，明确区别，不能在看到目标run误差后随意放宽。控制重放与重新运行神经规划是两件事；分别测试，不能混称。

### 8.4 最终场景接入

通过统一TaskSpec/SceneSpec表达原双世界目标、七个不规则航点及原时序、保持区间、2R5C等布局、卫星相对追踪目标。默认保留原任务数值，不以改目标和搬障碍代替解决问题。若开展不同难度新场景，独立命名，不替代原场景结论。

原83.5秒演示可以从同一新根初态重建，阶段交界仍可存在，但每阶段调用同一个规划器；不能把封存54.5秒末态接到新路径上冒称新全链。每段初态来自上一段实际末态和控制记忆。重放可逐段进行，但必须核对边界、全链绝对时间与累计动量账本。

已知未来目标模式可使用公开的卫星运动/受力协议，报告`KNOWN_MOTION_PROTOCOL`；在线模式只使用当前观测和声明预测，不能读取未来真实轨迹。两种模式不混报。无接触预抓捕/跟踪不称接触捕获。

最终至少完成一个完整链的冷启动规划、原生执行和独立重放，再以预先固定的不同规划seed重复。失败保留，DEV允许机制修复后建立新run，不删除旧run。视频只从实际保存状态生成，带任务/参考/实际/几何/力矩/动量/安全干预及方法身份。

### 8.5 滚动规划与墙钟边界

运动中接续必须支持非零初态，采用上次同一规划器计划热启动时保留冷/热启动标签。计划替换不能回拨仿真时间，不能在旧计划已过期时假装新计划及时到达。若计算在仿真步间暂停，明确叫`research_simulation`，显示规划墙钟时间；不能宣称实时50Hz规划。

真正实时模式应把计算延迟、旧计划执行前缀和预计应用时刻纳入初态/拼接检查，迟到安全拒绝。缺乏实时性能不阻止离线方法验证，但不能隐藏。不要把高频力矩伺服频率当成扩散规划更新率。

## 9. 数值与工程验收矩阵

本节数值是首轮开发目标。正式合同必须在独立校准任务上确认并冻结；不能把本节理解为这些精度已经达到。机械限位、原任务5mm/1°及非穿透等约束不得为通过实验放宽。不同类别量不得使用一个混合单位的最大误差。

| 门 | 初始要求 | 失败后动作 |
|---|---|---|
| MAP | 17→67及逆映射、单位、偏置、关节/执行器名称与原模型逐项一致；维度和限值自动核对 | 修参数提取与坐标，不改机器人 |
| BC | float64边界线性约束残差≤1e-10；时间缩放、mask和可变边界通过 | 修表示，不在执行中补状态 |
| FK | 对原生参照，在约定合法域内每个被测机体位置≤1e-6m、姿态≤1e-6rad | 查变换顺序、固定连接、末端偏置 |
| DYN | 同状态质量矩阵相对误差初始目标≤1e-6；偏置/逆动力学按分块绝对+相对量纲门校准 | 查惯量坐标、COM、armature、damping、速度约定 |
| PROP | 通过网格收敛；规划/高精度参照的最大任务误差≤位置/姿态门的20%，几何误差还要小于可用裕量的20% | 提高精度、修模型，不只加软权重 |
| GRAD | 在平滑样例上，归一化方向导数满足abs差≤1e-6+0.005×max(abs(AD),abs(FD))；检查多个FD步长，不单靠一个epsilon | 修图/符号/尺度；不光滑样例单列，不删除 |
| GEOM | 覆盖审计无已知漏包；冻结压力集里代理假安全数必须报告，已发现反例必须修复或限制适用域；最终全机原生检查 | 修代理与筛选，不能静默扩大排除表 |
| ACT | 名义67路raw torque不过限且预留裕量；原生执行raw torque不过限 | 先查模型与时长，冻结任务不得无限放慢 |
| TASK | 每个指定时刻/保持/追踪区间均按TaskSpec检查；继承任务双臂各5mm/1° | 对失败类型修学习/引导/表示，不重标目标 |
| COLL | 实体间隙≥冻结硬阈值，当前继承任务为0；细化标准含转动影响，最大几何步≤2mm | 加密、查真实碰撞，不以颜色替代门 |
| MOM | 用第4.7节校准冻结的世界动量残差门；全链和分段均报告 | 修物理/积分/坐标，不依赖本段动作幅度改阈值 |
| EXEC | 原始q67/速度/流形/跟踪/控制与全部任务满足原门，禁止状态注入；安全干预独立分类 | 定位规划—执行差异，不改写轨迹来源 |
| REPLAY | 同模型/配置下完整原生状态与独立控制重放一致，目标atol≤1e-10，时长和外力相同 | 先修完整快照/时序/非确定性，不能逐帧复制 |
| ARCH | 第3.3节所有职责测试通过，最终候选没有采样后任务恢复 | 修实际调用链，不只改README |
| REPRO | 干净隔离环境能跑软件smoke、模型校准和一条完整新规划—执行—重放 | 补依赖和真实资源，不交空路径 |

GRAD先覆盖每个能量项，再覆盖组合能量；每类至少8个有效方向和至少3种相异构型/任务，初步通过后扩到不少于64个机器人样例。边界点、近奇异、SO(3)π邻域、穿透/特征切换单独有测试和处理结果；不能只用远离障碍的零梯度样例通过测试。

FK/DYN的随机对照初期32例、通过后至少256例，包含两臂同时运动和非零基座姿态。若基于不同但等价坐标，先完成显式变换再比较，不能因矩阵形式不同就放宽到无意义精度。

有限样本零反例不等于全域严格证明；离散加密不等于连续时间碰撞证明；同机重放不等于硬件验证。报告必须保留这三条边界。

## 10. 工作包与自动推进条件

M0—M8是同一个长期目标的工作包，不是每完成一个就要求用户重新授权。每包优先交一个纵向可运行增量，再补覆盖；不要写完全部框架空壳才开始跑物理。

### M0：隔离、最小入口和状态落盘

**实施：** 检查工作区和来源；建立新worktree/分支、隔离Python环境、最小`ffgd`包和状态文件；适配器可编译原机器人并读取初态；把架构哨兵和只读验收测试放入测试集。

**交付：** `environment_manifest.json`、迁移表、`python -m ffgd.cli doctor`、最小可运行单元测试、可接续状态。`doctor`不能调用重型实验或训练。

**退出：** 新环境能导入、编译模型、读取物理维度/限位，并安全保存/恢复一个snapshot；不依赖旧任务包。能做则同会话立刻进入M1，禁止只给目录和TODO就结束。

### M1：统一样条与物理适配

**实施：** boundary codec、同一q/qd/qdd解码、可逆归一化、模型参数提取、可微全机FK、质量与偏置；先32例数值对照，再扩覆盖。

**退出：** MAP/BC/FK门通过；DYN关键分块与逆动力学达到预校准精度；所有输出使用世界帧/机体系的明确约定；未通过的项不能藏在“审计完成”中。

### M2：自由漂浮传播、几何、执行器与梯度

**实施：** 零动量传播及整路径AD；支持一般初态动量的设计与测试；全机几何代理/原生对照；名义raw torque和未驱动残差；分项与总能量方向导数。先独立固定小样条进行，不要求先训练。

**退出：** PROP/GRAD/GEOM/ACT数值门通过；发生真实接近或力矩约束的样例确有非零正确方向；代价对早期控制点的作用包含后续基座影响；完成至少一个实际67路参考跟踪及重放校准，但不得称为Diffusion结果。

**必须行为：** 若梯度成本过高，先剖析并优化batch/VJP/缓存/网格，不能把数百次整路径FD永久接到每步去噪。不能因缺GPU就删除自由漂浮、全机几何或力矩项。

### M3：先验数据与完整变量模型

**实施：** 生成/迁移并重检2,000条模型有效先验pilot；32条过拟合仅调试；训练完整自由变量模型；验证条件依赖、全噪声采样、完整自由维度有效性和边界mask。

**退出：** 存在真实训练权重、真实数据manifest、加载重现与有限采样；不是随机初始化网络、不是全零细节分支伪装全维学习；形成至少5条新噪声候选并通过基础有限值/边界/解码检查。M3不要求裸网络已解决所有约束。

### M4：去噪内引导纵向跑通

**实施：** 将M2后端接到实际采样器；准确60步与分散引导；仅通过独立验收选候选；架构哨兵运行；8—12个事先固定的开发任务覆盖无障碍、臂身障碍、接近限位、力矩约束。

**退出：** ARCH门通过；至少有无障碍和活跃臂身障碍两类任务从冷噪声→完整采样→合格候选，且无后置修复。所有失败保持；对图/场景反事实检查证实约束在采样时生效。

之后扩到40个冻结DEV任务。开发目标为≥36/40模型任务成功，但该数字是调试目标，不是保证或改变硬门的理由。若不足，继续第11节分诊；不能在8例成功后提前宣布整体完成。

### M5：物理闭环与归因初检

**实施：** 冻结一个跟踪器版本和一个验收profile；对预先选定的20个DEV任务使用采样前固定seed，依据模型分数预选候选，完整原生执行及重放。无合格候选也是失败单元，不从分母排除。

**退出：** 至少18/20通过全部执行门作为本阶段开发目标；每条成功都须全门通过，其他任务成功不能豁免该条碰撞或力矩违反；完成少量四方法配对初检（第13节），不以是否胜过基线作为停止其余工程实现的门。

失败若主要来自预测与执行差异，优先修物理模型、跟踪界、名义力矩余量和初态一致性；不能悄悄加一个基于目标的笛卡尔控制器替代计划。

### M6：通用任务、非零初态与计划接续

**实施：** 同一入口处理不同数量时序位姿约束、保持区间、时变目标；训练相应条件/非零初态窗口；完整初态/控制记忆接续；测量流形误差并处理适用域；冷/热启动分开。

**退出：** 至少三种不同约束数量、非零关节/基座速度接续、一个时变双臂任务通过同一规划核心；没有场景名分支或固定绕行答案；所有目标时间均被验收；不存在运动中强行零速度边界。

若表示不足，修改统一表示和训练范围，例如24/32/48控制点masked模板或联合分段样条，不为某一航点手工插入一条已知路径。变量数与边界模板版本变化后重训/校准并重跑受影响测试。

### M7：原最终组合场景的新全链

**实施：** 从新root run重建原双臂静态接近、七不规则航点/保持、实体卫星物理起动或声明初态后的追踪。默认保持原任务、时序、障碍、机械限位、位置/姿态和非穿透等物理要求。动量采用事先校准的新物理合同，并并列计算旧判据作为历史可比列；旧列失败不得写成“原门全通过”。如某实验明确要求旧动量门也必须通过，则它仍是额外必须门，不得被新版替代。所有阶段用同一FFGD入口，真实末态连续交接，并明示规划、数值和验收版本。

**退出：** 至少1条完整主链通过，再在已冻结的3个规划seed上复验。开发最终目标是同一冻结新版本3/3全门通过；不到则继续诊断，不能更换失败seed直到凑3条。修复后重跑同一整组3个seed，不把不同源码/权重版本的成功片段拼成3/3。该旧场景属于开发演示，不作为未见泛化证据。

交付两个实际视角视频、双臂世界轨迹与误差、全机最小间隙/关键对、q17/q67与流形残差、raw torque、基座与物理动量、逐阶段采样来源、安全干预与重放统计。媒体失败不重跑物理，用保存轨迹修复生成器。

### M8：冻结研究比较与干净环境交付

**实施：** 完成第13节匹配预算对照、未见任务评估和复现包；确认所有结论有明确分母和数据来源；检查新环境完整复现入口。最终验收独立于开发期成功日志。

**退出：** 架构与工程全门证据齐全；研究作用已测量并如实判定；无未披露失败或依赖。优势可以是`ESTABLISHED`、`MIXED`或`NOT_ESTABLISHED`，不由agent预先决定。

M8结果不能写成“永不失败”或“保证全面优于传统规划”。如正式TEST暴露缺陷，需要修复，先封存该TEST结果；用于修复的任务转DEV，新的正式评估重新冻结独立任务。

## 11. 失败分诊与结构性纠正

每次失败先保存最小可复现输入、代码/配置身份、原始日志和失败分类，再决定下一动作。常规可解错误不升级成用户阻塞。

| 失败签名 | 优先检查/修复 | 禁止的假修复 |
|---|---|---|
| 模型编译/导入失败 | 隔离环境、真实资源路径、必要适配器 | 大量复制历史包或硬编码旧电脑路径 |
| FK/质量不一致 | 固定帧、COM惯量、旋转顺序、限位/偏置、armature | 改原机器人使两实现“相等” |
| AD与FD不符 | 断图、标量化、归一化、旋转/距离符号、网格切换 | 改测试为只看零梯度 |
| 完整采样发散 | scaler一致性、v转换、schedule、dtype、边界自由基 | 输出裁剪后称网络本身正确 |
| 目标误差大 | 条件覆盖/初态、整路径导数、各项尺度、引导调度 | 固定基座IK终点替换世界目标 |
| 几何穿透 | 引导代理覆盖、穿透区梯度、激活对、目标冲突、先验形状覆盖 | 场景专用绕行、搬障碍、删pair |
| 轨迹始终无有效绕行模式 | 增加合理形状多样性、时间基表达、训练覆盖、版本化采样预算 | 无限重试同一分布直至挑到成功 |
| raw torque超限 | 惯性/偏置、物理时间、名义前馈、跟踪裕量 | 裁剪力矩后不记raw violation |
| 执行误差大 | 预测—原生差异、控制器固定模型、初态及延迟、流形域 | 任务反馈重新规划整条参考 |
| 动量残差 | 物体范围、参考点、坐标、外力账本、积分收敛 | 扣除每段初值追认、加无意义动作抬阈值 |
| 重放不一致 | 完整snapshot、warmstart、外力/ctrl时序、版本/线程 | 逐帧复制真实状态 |
| 速度慢/OOM | 批处理、缓存固定模型、VJP、checkpointing、分块、混合精度校准 | 删除关键物理项或隐去真实耗时 |
| 无学习收益 | 匹配预算、条件依赖、数据覆盖、有效自由维度、训练/推理一致性 | 弱化基线、换成功子集、声称网络调用多就是贡献 |

同一失败签名在3个机制未变化的尝试中没有改善时，停止盲调这一方向，进行一次有界根因实验并更换假设/实现；不是停止整个项目。记录`hypothesis → intervention → expected_observation → actual_observation → next_action`。不要求每次只改一行，但归因实验一次只改变一个主机制。

先做能区分原因的最小测试，再跑大实验；没有改变机制、输入或数值条件时不要重跑已知确定性失败。架构性修复必须回到统一模块，不创建新的场景包。

```text

                  → FAILED_NEEDS_FIX
                  → INTERRUPTED_RECOVERABLE
                  → PARTIAL_UNKNOWN
```

每个工作单元记录：ID、所属里程碑、源码/配置/输入hash、目标、命令、预算、进程身份、起止时刻、退出码、主要数值、输出manifest、下一动作。通过状态必须链接真实证据，不能手工只改JSON。

### 12.3 继续循环

```text
读取适用指令、MASTER、state与HANDOFF
    ↓
核对HEAD/输入和活跃进程，避免重复运行
    ↓
找最前面的未通过依赖门
    ↓
选择一个可完成且有信息增益的工作单元
    ↓
实现 → 相关测试 → 必要实验 → 结果归类
    ↓
若失败：修复/更换假设，不反复询问“是否继续”
若通过：更新证据，自动推进下一单元
    ↓
周期性检查点；继续直到工程完成或真实外部中断
```

`next`命令负责列出下个可执行工作单元；它不是自动编程代理，也不能凭一个Python while循环自动启动不存在的Codex会话。编码与决策由当前实际运行的agent完成；外部训练worker只有在确实启动并记录后才称正在运行。

### 12.4 中断与幂等恢复

写检查点采用临时文件＋原子替换，包含网络/优化器/RNG、数据迭代器、当前工作单元、模型/场景/时间身份。训练可以从已验证checkpoint恢复；未知半写文件隔离，不覆盖。

原生执行续作必须经过独立的中断恢复测试，保存完整积分状态、控制记忆、输入游标和已完成步数，并与不中断执行比较。没有通过该测试前，中断物理run保留PARTIAL，创建新run重新执行；不得把两次不同初态运行拼成同一连续轨迹。

已完成、身份未变的工作单元再次调用返回现有结果而非重跑。源码/关键配置改变时创建新单元，旧结论不改。不要继承旧实验“只能resume一次、禁止以后读结果”的规则来阻塞新研发；同时不重开旧实验伪装新证据。

PID锁核对host、PID、启动时间和命令签名；不能根据一个过期PID杀掉其他进程。一台机器默认一个重型计算worker，另可运行轻量测试/只读检查；多agent只有实际工具支持时才启用，禁止虚构独立审查agent或并行结果。

### 12.5 资源与预算

不设置一个脱离实测的超小项目总时限；先做短profiling，按每批数据、训练更新、候选、原生步和输出规模预算。每个工作单元保留执行＋重放＋写盘余量，分块运行，达到资源边界安全保存后续作。

默认使用已授权资源，最多约80%可用RAM/VRAM给本任务，CPU预留至少一个逻辑核；实际数值根据机器与用户已有任务自动下调。最小可用空间建议10GiB并结合下一单元预计输出保留2倍写盘余量；不足则优先压缩新产生的可再生诊断、迁移到已授权可用盘或缩小批量，不删除用户/历史证据。不自行使用付费云资源。

模型只编译一次并按scene cache复用；不要为每条候选复制数百MB模型或逐次重新序列化哈希。不为所有中间候选保存全机高频矩阵；保存必要控制点、阶段数值与失败最小证据。已执行计划必须保留足够原始控制和完整状态支持重放。

允许根据真实瓶颈增加数据/训练/采样预算，但每次形成新配置版本并记录理由。正式对照的预算冻结，不允许单独给主方法无限资源。文档工作不得反复替代算法推进：每次正常工作循环应新增代码、测试结果或有辨识力的实验结果之一。

### 12.6 最小状态输出与会话交接

正常进展只报告：当前里程碑、已执行动作、最新真实结果、下一动作；没有状态变化不刷屏。出现真正阻塞时给出具体缺口与最小解除条件，不反复发送同一问题。

任何受限退出前写`HANDOFF.md`：当前HEAD与未提交内容、最近PASS、最早FAIL、仍在运行的真实PID、最新checkpoint、下一条真实可运行命令、恢复注意事项。不能只写“以后继续”。不得因为会话中断把未测项填PASS。

## 13. 研究比较与收益判定

### 13.1 先做四组，不继续堆版本名

| 组 | 定义 | 主要问题 |
|---|---|---|
| A | 完整FFGD | 主方法 |
| B | 同一训练权重，关闭物理引导 | 先验本身的质量 |
| C | 多初值非学习样条＋同一物理代价 | 学习先验相对强非学习初始化的作用 |
| D | 同一Diffusion先无引导生成，再等预算后处理 | 去噪内交互是否优于采样后修正 |

D和C可以在比较专用入口执行优化，但不能被主方法A偷偷调用。C应有多个合理初值而不是只有一条直线；允许公开初态/目标构造的通用初值，禁止使用隐藏解。B仍用完整硬验收，不能关闭引导就同时取消约束。

A有效后，增加“无碰撞引导”“无执行器引导”两项机制消融；同一候选seed、相同网络和验收器。任务本身应包含足够约束活跃案例，否则消融不降性能不等于实现错误，需报告激活率。

### 13.2 公平与数据隔离

相同TaskSpec、RobotSpec、初态、轨迹表示、时长、候选数、检查标准。所有方法记录真实墙钟、网络调用、传播步/批量、梯度调用、几何查询、实际执行与失败。

公平不能仅说“迭代次数一样”：报告匹配墙钟预算与匹配主要物理调用预算两种视角；网络推理成本计入A/D总时长，CPU/GPU同步计时和预热分列。超过预算算资源/超时失败，不能隐藏额外重试。

旧七点与旧2R5C演示明确属于DEV。新任务由预先冻结规则产生，划分按初态族、轨迹族、目标邻域与场景族隔离。用于证明任务可行的见证轨迹存于独立目录，运行时PlannerInputs不包含它；规划器不能按task_id查答案。有限尝试失败不等于物理不可达证明。

### 13.3 建议正式规模与统计

开发初检：12个配对任务，先验证方法身份与计时口径。正式目标：至少200个新的冻结任务，覆盖普通、臂身约束、关节/力矩紧约束和时变任务；最终组成在看到测试结果前冻结。每任务5候选，失败/未完成保留分母。

主方法最终至少3个独立训练seed，采样seed另列。每个训练seed均评估200任务；这600任务-模型单元不是600个独立物理任务。对有学习组使用对应权重做配对消融；C按同一任务、相应随机重复评估。模型统计对全体候选做；闭环验收预先固定至少60个任务子集并在3个训练seed下执行各自预选候选，完整重放。报告模型全集与物理子集的范围，不把子集成功升级成全体执行成功。

上面的规模是最终证据目标，不阻塞早期原型；资源受限时分批接续，清楚标记未完成部分，不用较小样本冒称已达此规模。

至少报告：候选可行率、任务成功率、双臂位置/姿态、最小实体间隙、各约束违反率、名义/原始实际力矩、基座运动与物理动量残差、总规划耗时与长尾、独立重放、冷/热启动、几何安全干预、合格候选间多样性。

多样性在同一冻结任务上统计。预选20个多模态诊断任务，目标是其中有可验证的两种或更多有效几何运动模式；数值不同不自动等于拓扑不同，不强制宣称五种模式。判据和描述尺度先冻结，重复采样不能被算成独立任务。

成功率置信区间按任务族/训练seed考虑相关性；不要把一个任务的五条候选当五个独立任务。质量指标既给各自成功集合，也给共同成功集合；失败不能从成功率分母消失。

### 13.4 三个判定不合并

- 架构通过：职责测试、来源链和物理引导真实成立。
- 工程通过：规定任务与连续链在硬门下完成，独立重放通过，无冒充路径恢复。
- 学习收益：预先指定主指标在匹配预算下是否改善，其他指标与置信区间如实报告。

不能把较低噪声MSE、较小训练损失、网络调用次数、好看的视频或较大的引导改变量当成学习收益。若收益混合或未建立，保存有价值的工程实现与反例，下一次研究迭代针对分布/表示/引导机制，不篡改本轮结果。

## 14. 完成定义与交付物

### 14.1 完成清单

只有以下全部有真实证据时，才可标`COMPLETED_ENGINEERING`：

1. 新主入口从公开任务和随机噪声产生完整轨迹，无历史答案、无后置主要规划器、无场景专用绕行。
2. 真实去噪循环中多次交替执行网络与完整物理引导，非末步修正被后续网络消费。
3. 自由漂浮传播、整路径梯度、全机几何、67路执行器需求分别通过数值对照。
4. 轨迹边界、时间与训练/采样/验收/执行表示一致；支持最终接续所需的非零初态和任务类型。
5. 数据来源/划分、TRAIN-only归一化、训练权重与实际调用可追溯；新主模型不是随机模型或固定低秩旧残差包装。
6. 验收器只读并覆盖全部硬门，执行保留完整实际状态，安全辅助不冒充纯规划成功。
7. 原最终组合场景作为新全链完成规定复验，任务数值没有偷偷更改；包括真实卫星起源/目标运动来源、实际末态连续交接及完整重放。
8. 未见任务研究比较与消融按冻结协议完成，学习作用如实判定，不要求伪造全面领先。
9. 干净环境可运行文档中的真实命令；必要模型/权重/样例有实际路径和hash，无未披露依赖。
10. 所有已知失败、限制、资源成本和未建立的主张披露，旧结果保留。

任一项缺失，总目标仍未完成。可以报告`ARCHITECTURE_PASSED`或`ENGINEERING_PARTIAL`，不能拿局部状态代替总体。
