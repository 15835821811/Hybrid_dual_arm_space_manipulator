# V6.1-A：连续体臂形与有限体积几何审计

## 1. 阶段结论

V6.1-A 已实现并通过正式审计。它在不改变 `v6_lite_6` 控制命令的前提下，增加了一条只读影子链：

```text
10 维形状变量 + 实际浮动基座位姿 + 任意弧长
                    │
          ┌─────────┴─────────┐
          │                   │
   5 段解析 PCC          URDF 一致离散 FK
 p,R,Jp,JR / 连续曲线      60 关节实际链基准
          │                   │
      PCC 管体代理       61 胶囊 + 1 原几何兜底
          └─────────┬─────────┘
                    │
          移动目标卫星 OBB 净空
                    │
      与 MuJoCo collision geom 独立对照
```

这条链当前不会被 `hierarchical_qp.py` 或 `run_v6_lite.py` 导入，不会改变 QP 解、速度斜坡或 67 维力矩输出。将臂形约束接入控制属于 V6.1-B，不属于本阶段。

## 2. 统一模型合同

版本化合同为 `v6.1-a.1`，集中定义在 `v6_lite/continuum_model_spec.py`：

- 5 个 PCC 段，长度为 `[0.3, 0.3, 0.3, 0.3, 0.2975] m`；
- 30 个离散模块，前 29 个为 `0.05 m`，末段为 `0.0475 m`；
- 10 维规划形状变量到 60 个低层连续体转轴的分配矩阵 `B` 及伪逆 `B+`；
- 连续体安装变换、轴方向、关节/刚体名称、末端偏置与声明工作域；
- 原始 URDF SHA-256 和模型合同 SHA-256。

实际低层构型使用

```text
q_p = B+ q_a
e_perp = q_a - B q_p
```

监测是否偏离理想低维形状子空间。正式五场景 trace 的 `||e_perp||2` 最大值为 `3.208864e-6 rad`；该量只被记录，没有反向修改控制器。

## 3. 两种臂形模型

### 3.1 独立离散 FK

`DiscreteContinuumKinematics` 直接解析 URDF 固定变换、转轴与父子关系，不调用 MuJoCo 的 `xpos/xmat` 作为计算结果。它用于核对轴序、符号、固定变换和 60 维实际关节状态。

在 10,000 个冻结构型上：

| 指标 | 最大误差 | 门槛 |
| --- | ---: | ---: |
| 独立 FK 对 MuJoCo 位置 | `4.920180e-15 m` | `1e-6 m` |
| 独立 FK 对 MuJoCo 姿态 | `1.154239e-7 rad` | `1e-6 rad` |

### 3.2 解析 PCC

`ContinuumShapeModel` 对任意 `(q_c,T_b,s)` 返回：

```text
p(s), R(s), Jp(s), JR(s)
```

单段采用常应变矩阵指数，位置积分在零曲率附近切换到无除零的级数形式；导数由矩阵指数 Fréchet 导数得到。256 个构型、2,560 个坐标方向的中心差分检查结果为：

| 指标 | 最大绝对误差 |
| --- | ---: |
| `Jp` | `3.911673e-10` |
| `JR` | `2.136328e-10` |

PCC 导数正确性与 PCC 对实际离散链的近似误差分开报告。31 个全臂弧长点 × 10,000 个构型的模型差异为：

| 指标 | p95 | 最大值 |
| --- | ---: | ---: |
| 位置差 | `43.040812 mm` | `55.390652 mm` |
| 姿态差 | `0.012650 rad` | `0.235566 rad` |

这些差异是 PCC 与集中离散关节链之间的模型差异，不是数值程序容差，不能删除或伪装成实现误差。

## 4. 有限体积包络与距离

目标卫星使用随其自由关节平移和旋转的 OBB。连续体实际碰撞几何共有 62 个：

- 61 个远端几何分别由有限半径胶囊负责；
- 安装座 `collision_0003` 明确保留原 MuJoCo 几何检查；
- 每个 collision geom 恰有一个审计责任归属。

胶囊由实际 mesh/box 顶点拟合并检查顶点覆盖。PCC 管体半径还包含离散链/PCC 差异、轴向/弧长采样余量和 `0.1 mm` 数值余量；五段正式标定半径为：

```text
[68.366971, 85.048842, 88.464859, 92.534271, 88.417893] mm
```

这组数值是保守代理半径，不是机械臂的物理半径。它较大，正是当前 PCC 近似误差不可忽略的量化结果。

正式集合含 8,000 个标定构型和互不重叠的 2,000 个留出构型。留出集中胶囊轴超出 PCC 管体包络的构型数为 0；最大半径超额为 `-17.212415 mm`。

距离接口显式返回查询是否被 `distmax` 截断。达到截断上限的值不会被称为精确净空。

## 5. 假安全与梯度审计

正式比较包含 10,000 个机械臂—卫星相对几何案例：

| 类别 | 案例数 | 实际低于 5 mm 的案例数 |
| --- | ---: | ---: |
| 盒面 | 1,667 | 1,100 |
| 盒棱 | 1,667 | 678 |
| 盒角 | 1,667 | 539 |
| 旋转目标 | 1,667 | 783 |
| 臂中段擦碰 | 1,666 | 1,150 |
| 主动穿透 | 1,666 | 1,666 |

“假安全”定义为代理净空 `>= 5 mm`，但其负责包络的 MuJoCo 几何净空 `< 5 mm`。结果为：

| 检查 | 结果 |
| --- | ---: |
| 胶囊代理假安全 | `0 / 10,000` |
| PCC 管体代理假安全 | `0 / 10,000` |
| 正式移动目标 trace 的 PCC 假安全 | `0 / 275` |
| 胶囊净空梯度最大绝对误差 | `5.910848e-10` |
| PCC 净空梯度最大绝对误差 | `1.986879e-10` |

最近特征发生切换的非光滑点不用于梯度中心差分判据，但仍参与距离与假安全统计。

## 7. 证据边界

零假安全是固定有限集合上的回归证据，不是全状态域的数学安全证书，也不是连续时间 CCD 证明。V6.1-A 没有把 PCC/胶囊约束加入 QP，没有处理采样执行误差预算、异常备份控制或参考进度管理。当前在线安全责任仍由 `v6_lite_6` 原 MuJoCo 几何 CBF 承担。
