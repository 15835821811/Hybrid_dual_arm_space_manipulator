## 结果及决策

原计数精确复现，实际安全 225 个、低于门槛 799 个，假安全为 0。这里的实际几何是声明的连续体碰撞几何对目标 OBB，尚不是整机或闭环任务结果。

| 原代理状态 | 实际安全 | 实际低于门槛 |
| --- | ---: | ---: |
| SAFE | 35 | 0 |
| BELOW | 172 | 799 |
| UNKNOWN | 18 | 0 |

172 个实际安全案例的代理上界已经低于 5 mm。因此，同一定义的代理最小距离自身低于门槛，继续数值细化不能将其变为 SAFE。这只能归因到整体代理几何差异，不能据此单独指认半径、PCC 形状误差或某一个裕度的贡献。上下界结论沿用原解析代理假设和经验浮点 pad；该实现没有形式化浮点区间认证，真实链包络仍是有限证据范围。

| 18 个 UNKNOWN 的诊断 | SAFE / BELOW / UNKNOWN | 最大实际点数 | 停止原因 |
| --- | --- | ---: | --- |
| B.1 预算 255 | 13 / 0 / 5 | 155 | 全部达到固定 1 mm 距离容差 |
| B.1 预算 510 | 13 / 0 / 5 | 155 | 同上，预算未耗尽 |
| B.1 预算 1020 | 13 / 0 / 5 | 155 | 同上，预算未耗尽 |
| Batched 255/128 | 18 / 0 / 0 | 133 | 全部完成门槛决策，最多 69 叶 |
| Batched 255/512、510/512、1020/512 | 各 18 / 0 / 0 | 各 133 | 非计时结果与默认配置相同 |

B.1 剩余 5 个 UNKNOWN 是固定距离精度停止后仍跨门槛，不是已证的几何拒绝。决策查询的 gap 也不代表距离精度曲线。默认在线查询已解决本子集，扩大点预算或叶上限均没有新增收益，故停止这条预算扩张支线。

本轮实际距离截断数为 0。一般遇 0.5 m 查询截断时，只能报告距离至少 `0.5−1e-12`，代理差异仅有下界，上界应为空。保存的计时包含首例，18 例的查询分位数不能作为全 1,024 例在线计时或完整控制周期计时。在线查询仅执行了这个子集；不能将 35+18=53 写成全人口在线实测结果。
