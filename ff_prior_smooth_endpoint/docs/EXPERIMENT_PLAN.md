## 损失与参数步冻结

设q为双臂位置/5mm、姿态/1°四组误差范数的平方，采用

Lworld = tau * log(mean(exp(q/tau))) + 0.05 * mean(q)，tau固定为1.0。

用减去最大值的稳定logmeanexp实现，不扫温度，不根据新结果改权重。该平滑目标仅用于训练梯度。实际接受仍检查原非平滑Q=max四组误差范数，原物理门一项不变。

事件与控制均计算当前预测上的完整102维真实自由漂浮有限差分梯度；每份212次耦合前向，标准化epsilon=.01，保留半步2%、方向5%与256/512积分收敛检查。两个样本世界参数梯度等权平均；其范数限定到当前普通梯度的10%，普通v+0.05教师localG保留，全梯度clip1。M1普通base梯度也由事件/控制两样本的v+localG等权平均，区别于旧轮仅事件的base，因此旧轮10/24不是隔离某一个改动的因果基线。

AdamW lr2e-4，保留原普通参数设置。从同一前置权重/优化器提出base与combined步；检查固定缩放1、0.5、0.25，接受须事件与控制各自Q严格下降，原已合格的任何分项不越门、有限且在关节域内。该诊断不是MODEL_VALID或力矩资格认证。接受缩步保留完整combined AdamW矩及一次step，拒绝恢复前态仅提交base；M1全部恢复，不保留任何更新。
