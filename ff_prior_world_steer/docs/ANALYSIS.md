## 具体瓶颈

本轮19,270份逐网格边报告中，12,436次因穿透终止，4,558次要求加密网格，2,276次边筛选通过。“要求加密”包括同一边逐级检查，不能把它们全记作不同候选失败。12,436次穿透试探中，6,177次（49.67%）的最小几何对为v7_capture_3与fore_arm_link，也就是第4个障碍和刚性臂前臂。接下来还有腕部、末端与多个障碍的干涉；只检查末端位置不足以解决全臂避障。

1. **目标梯度与避障方向仍分离。** 新机制的世界Jacobian只优化双臂终点残差；碰撞信息主要用于事后拒绝。它能继续保留中间状态，却不知道应沿障碍切向绕行。源码steer.py中的方向由世界残差计算，Connector.edge才作几何判断。这是具体实现局限，不是“微重力一定无法规划”。
2. **重复的失败方向消耗探索机会。** 世界方向共3,548次，只接受561次（15.81%）；961个父节点被用于该方向，产生2,587次同父重复尝试。2,987次世界方向失败中，2,372次属于同父重复失败，占79.41%。缓存方向和固定1/.5/.25尺度在相同父状态下重复，缺少利用已知拒绝信息改变方向的机制。
3. **有时间并不等于有可用绕行方向。** 最优节点仍余12秒，所有节点都未过原位姿门。当前主要证据指向几何方向选择和重复搜索；不能以“27秒已用尽”作为该最优节点停止原因。
4. **提案通过目标初始化不等于绕障可行。** 15份初始化种子均能在无几何资格的模型网格命中目标，但中间路径仍可能穿透；当前65维网络没有障碍条件。目标、障碍和全机状态之间的耦合仍由规划器承担，本轮不能声称网络自主绕障成立。
