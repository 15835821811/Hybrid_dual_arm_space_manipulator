# 固定TRAIN世界目标多轨迹与耦合目标损失：实验计划

## 问题与主张
上一轮低维Diffusion虽最终50/50合格，但修正前位置误差中位数约64mm，修正成本高于样条与学习均值。TRAIN只有3条障碍轨迹，没有同障碍条件下的多轨迹组。
C1：少量真实合格的固定目标轨迹能够补足局部多解数据覆盖。
C2：在同数据、同初始化和噪声下，局部自由漂浮目标误差正则能减少采样后的世界目标修正成本。
反证：不能将均值回归、额外预算、放宽物理门槛或选择性省略失败造成的改善写成Diffusion优势。完整目标仍遵循ff_prior_feasible/docs/CORE_GOAL.md，包含最终真实扩库。

## 冻结数据阶段
8个已有TRAIN世界目标，来自5个家族：3个障碍目标、同家族3个较大运动目标、另2个初态变化目标。这里不是8个独立家族。
每目标6次提案，共48次。原合格轨迹加成对±0.03/0.06/0.10rad平滑弓形扰动，世界目标保持原值；使用原修正器和独立验证器。每条除物理合格外，还需与同目标源轨迹及之前新轨迹的控制点RMS差异≥0.005rad。此差异不等于不同拓扑路径或strict_multimodal认证。
预选(目标,变体)=(0,0),(1,2),(2,4),(3,5)做真实67力矩执行与独立重放；不合格不替补，不把未执行行批量升级。执行失败行从新TRAIN索引排除，原始证据保留。
全局生成质量门槛：至少39/48新标签可训练，3个障碍目标各至少2条不同合格标签，预选4/4执行通过。这是小批生成覆盖门槛，不恢复大主库同目标5条准入要求。即使全局质量门槛未通过，单条独立合格数据仍可用于探索训练，不能用于宣布扩库门槛通过。

## 耦合敏感度与训练
所有TRAIN原有及新合格数据实际加载；VAL仍为原48条，DEV/TEST不用于训练。按完整task_hash缓存，每个已有合格TRAIN目标取首条标签作为局部锚点。
34方向=17个平滑终端方向＋17个零终端弓形方向；每方向均完整128网格自由漂浮传播。加基准、2次半步、混合方向及未表示时间方向检查，每锚39查询，最多180锚/7020查询/898560积分区间。
这只是局部34方向代理，不是完整119维精确梯度，也不是物理验证。半步相对误差≤2%、小混合方向误差≤5%为局部数值门槛；独立未表示时间方向误差必须报告，不能藏掉近似局限。
两份新模型使用同数据、同TRAIN拟合时间基与ridge中心、同初始权重、batch/噪声序列、1800更新及固定最后检查点。v-only与v+0.05局部目标误差损失仅在正则项上不同；VAL不参与梯度或权重选择。每份新模型需实际见到全部TRAIN行。未增加障碍网络输入，以隔离数据及目标损失；场景条件消融仍属后续目标。

## 配对smoke
原10个VAL任务与原5种子；强样条、上轮冻结低维Diffusion、增量数据均值样条、增量数据v-only Diffusion、增量数据目标损失Diffusion，共250候选，最多50次选中执行＋独立重放。
所有方法均5候选/任务，每候选上限113耦合查询、15872积分区间、15秒；同一物理修正器、选择规则及验证器。完整作业上限5400秒、2 CPU线程。离线生成/敏感度/训练与在线候选成本分账；额外方法仅增加总对照规模，不增加任何方法独享候选预算。
稳定性：两组候选合格率各≥90%，每任务≥4/5，执行10/10。探索性优势：不降低合格与执行成功，同时相对强样条和新增均值基线均有更多执行成功任务，或实际查询和时间都降低≥10%。单轮开发结果不能替代多种子可复现优势。

## 门槛、交付与后续
保持17→67、完整初态、自由漂浮、全机几何、仅不穿透、5mm/1°、2mm几何变化及原动力学约束。原冻结DEV仅核验，不启动pilot、study、strict_multimodal、最终TEST或生产规模。
M0 软件/真实TRAIN回归 → M1 48次生成＋4次预选审计 → M2 TRAIN敏感度＋同预算双训练 → M3 冻结配对执行 → M4 原始证据、保留和恢复审计＋中文报告。
若敏感度阶段受阻，目标损失训练保持BLOCKED，仍完成合格数据、v-only训练及不依赖它的比较。不得用缺失代理当零梯度冒充目标损失实验。
