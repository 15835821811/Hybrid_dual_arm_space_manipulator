- 实际状态与积分参考均无连续体±1rad越界。先验最大实际坐标静止0.9600000714rad、漂移0.9599999994rad；最大参考约0.9600000000rad。0.96是原0.04rad控制缓冲形成的规划边界，硬验收仍1rad。

## 修复内容

`adapter.py` 统一采用 `RobotAdapter.lower/upper`：

1. 对实际规划状态计算向内的速度边界，沿用旧0.04rad缓冲、速度/加速度储备。
2. 根据20ms控制周期内十个2ms线性速度坡道，逐子步计算积分参考的位置线性不等式，与实际状态边界及原碰撞QP同时求交。
3. 每个真实仿真步记录后检查实际状态和积分参考，越界或QP不可行则保留记录并停止。没有裁剪真实qpos/qvel，没有将积分参考强行截到边界。
4. 原生关节范围只检查 `jnt_limited` 的真实限位，采用原合同掩码，不再把无限位关节占位[0,0]误当成物理限位。

4/4软件测试通过：1000组随机状态的可行子集逐一核查十子步积分边界、实际状态接近边界必须向内、参考接近边界时独立受约束、不可行外向状态明确拒绝。软件测试不代替以下实际执行。

工程层：本轮实际/参考工作域遗漏已修复，四记录通过完整物理验收和独立重放。数值结果不提供连续时间安全证明、普适安全保证或硬件实验结论。

数据层：这是四条开发场景执行证据，没有扩库，没有升级任何未执行样本。

学习层：没有新训练；没有证明网络独立生成时序任务轨迹的能力提高。共同控制器仍承担动态参考跟踪。

收益层：现有终点先验改变了冗余运动，但本轮没有增加任务成功数或改善总体跟踪；漂移场景更差。不支持将这个适配设为默认优胜方法，也不能外推为原静态late4或Diffusion家族无效。

只有两个固定开发场景；时间序列帧不是独立实验重复。静止/漂移用不同原冻结种子，二者差值不能单独归因目标运动。
