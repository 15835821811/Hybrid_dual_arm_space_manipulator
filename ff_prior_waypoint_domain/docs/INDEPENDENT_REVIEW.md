## 工作域实现与同一性

`reference + 0.002*(k-k*(k+1)/20)*previous + 0.002*k*(k+1)/20*velocity`。

代码逐一限制 k=1…10 在带 0.04 rad 缓冲的域内；与 advance_native 的实际线性坡道/矩形积分一致。实际状态每步记录后检查并显式失败；没有发现新适配器通过修改 qpos/qvel 或裁剪积分参考隐藏越界。实际 barrier 是反馈工程约束，不是带动力学不确定性的数学不变集保证。

## 结果支持与不支持的主张

**支持：**原先两个先验轨迹分别达到约 1.1867 和 1.2327 rad，超出 V7 连续体域；新适配器在相同任务目标、初态与冻结先验下使两个案例实际和积分参考都留在域内，并在已有原生执行/重放验收中通过。两基线原本已通过，所以成功率应分别报告为先验 0/2→2/2、基线 2/2→2/2，而非把四条新通过都归功于先验。

**不支持：**先验提高相对于同轮控制基线的跟踪、效率或一般成功率。漂移 C 均值误差提高 53.39%，最大误差提高 436.40%；R 均值也提高 21.33%。漂移关节路径长度 4.3257 对 3.5367 rad，总绝对力矩积分 7.4113 对 6.0854 Nms，也不呈现相应效率优势。静止 C 最大误差虽微降约 0.000069 mm，均值略升；不能挑这一项声称整体优势。

修复前后漂移先验 C 均值由约 0.1036504 降到 0.0883812 mm，只证明该修复改变并改善了此项先验自身指标；不能替代与基线的比较。旧先验已违反硬域，不应把其低误差视为合格性能竞争结果。

模型输入只有终端目标，没有显式路径或目标 twist 条件；路径跟踪主要由在线任务控制器完成。结果不证明 Diffusion 学会不规则路径、漂移目标动力学、原生 V7 动态泛化，也不支持硬件、接触抓取或连续时间安全保证。
