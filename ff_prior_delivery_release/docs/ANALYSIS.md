## 训练究竟做了什么

本轮沿用稳定的v去噪损失＋0.05教师附近局部位姿近似损失。复用13495个身份一致的旧局部G矩阵；这些固定目标已覆盖新增128条轨迹，因此没有新锚，也没有新增G物理查询。旧锚的任务、教师样本ID、参考轨迹、基底、矩阵hash和原数值检查均绑定。全部13966行实际进入训练；13886行的数组通过已冻结字节缓存复用，128条新数组逐条读取。没有把复用缓存写成重新生成物理数据。

**本轮没有实现新的真实非线性世界终点梯度训练。** 这是delivery_v1明确选择的可用路线；旧世界监督/四组配对训练中D=0.914089及旧DEV BLOCKED继续保留。它们不能被本轮工程通过改写。严格世界目标仍由完整自由漂浮传播、后四步修正及独立验收来落实。

日志有一次SciPy有界优化内部步被裁回边界的RuntimeWarning。它不是已输出轨迹被豁免：本轮所有输出仍经过范围、有限性、DDIM回写、运动、全机几何、世界目标和执行重放检查。未发现未解决的输出越界或数值错误。保留该日志供独立审查，不因此重跑实验。
