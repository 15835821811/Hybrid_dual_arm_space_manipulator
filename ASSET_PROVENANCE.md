# Model asset provenance and publication status

The V6-lite runtime uses the URDF at
`dual_arm_space_robot_2026/urdf/dual_arm_space_robot_2026.urdf` and the 75 STL
files referenced by that URDF. They were copied unchanged from the project's
current local research bundle so that the committed model identity and
validation hashes remain reproducible.

The URDF header identifies the SolidWorks-to-URDF exporter and its upstream
author. That header describes the export tool; it does **not** establish the
authorship or redistribution licence of this robot model and its meshes.

No open-source licence or public redistribution grant for these model assets
was supplied with the source bundle. The repository should therefore remain
private unless the repository owner confirms the relevant rights and adds the
appropriate licence/notice. This notice does not replace such permission.
