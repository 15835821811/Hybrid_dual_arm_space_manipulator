## R1 优先：不改模型权重的去噪内引导对照

目的：在相同公开条件下，判断“后期多次轻量修正”能否比“最终一次集中修正”减少终点/碰撞失败；区分结果来自网络还是共同修正。

先实现新模块、新输出目录，不修改旧冻结包。沿用v预测、float64采样状态和现有16步时间序列，不迁移参考项目的epsilon网络或63步实现。旧13774模型/codec必须通过现有哈希重载。

首次只用8个既有TRAIN固定目标，按场景有无障碍各4个，从endpoint_mode_00…15的v0记录按样本ID哈希确定，选择只依赖元数据，不看规划结果。固定两个采样种子20262601、20262602，每任务每种子每方法5候选；共320候选，所有失败仍计入预算。四方法：

1. 强结构样条＋共同修正。
2. 旧条件均值＋共同修正。
3. 旧Diffusion＋原最终干净步修正（复现对照）。
4. 同一旧Diffusion＋后4个干净估计上的分段修正。

新方法在迭代12/13/14/15分配最多27/27/27/29次耦合查询，累计仍≤110；不能每次重新给110。其余方法同样≤110，网络候选恰16次调用。导向传播仍用128间隔，最终独立验证继续调用原验证器，不以导向网格代替。所有方法按同一候选排序规则选一条，预选的16个TRAIN任务×种子单元每方法最多执行一次，共64次执行/独立重放上限；不得失败后换候选重试。

每次在clean预测上引导后，必须按未修改的当前x_t重新计算epsilon，使x_t=sqrt(alpha_t)*guided_x0+sqrt(1-alpha_t)*epsilon成立，再做下一步DDIM更新；在最终alpha_next=1时直接返回修正clean。每步记录分解残差、有限性、范围和已消耗查询。固定完整物理初态，不能直接硬写教师终点关节角。

实现测试先验证：16网络调用、110全局上限、恢复不重复、指导后DDIM恒等式、浮点有限性、已合格目标不因避障被破坏、冻结任务哈希不变。真实TRAIN运行分别记录raw、共同预处理、每次引导、最终验收与执行，不用测试夹具充当机器人通过证据。
