# 同预算残差学习实验计划

日期：2026-10-15。基线HEAD：6d552680；分支v7.1-lightweight-free-floating-prior。沿用现有docs布局。

## 两个待检验主张

| 主张 | 必要证据 | 未成立时的解释 |
|---|---|---|
| C1 末步修正能减少反复撤销约束的成本 | 同一冻结模型、同任务种子，末步修正与两步修正在同一总预算下比较；记录网络/时间先验/平滑/修正误差 | 调度简化没有带来稳定收益，保留旧实现 |
| C2 固定世界目标的最小残差监督能降低修正成本 | 微调与冻结模型均末步修正；VAL和DEV都不降低合格/执行数，候选耦合查询至少少20%，wall不增加 | 学习收益未成立；优先更简单的样条方案 |

排除误判：显式求解器的成功不能归因于Diffusion；数据MODEL_VALID不升级为已执行；高噪声数值稳定与目标准确分开。

## 必做实验块

1. 冻结和诊断：保留旧HEAD、旧数据/证据及用户脏文件；现有VAL日志30/30出现修正后下一步误差上升。实际6 TRAIN+6 VAL各一个种子，记录public initializer、t999/中间/最后两步network clean、时间先验投影、平滑、每次修正；额外探测单独计账，不用DEV调试。
2. 小规模目标残差监督：从原30 TRAIN家族每家族按固定哈希选一个世界目标，公共初值生成器+同一有界修正器各生成1条；6 VAL家族各1条仅验证，不输入梯度。只有完整MODEL_VALID且固定世界目标合格才可训练。原166 TRAIN与旧checkpoint保持。
3. 训练与选择：8 TRAIN固定高噪声样本80次拟合检查，末loss<=初loss30%才进入正式训练。重新从旧checkpoint开始240次微调、batch16、lr1e-4、v预测+clean残差MSE、终点权重4；scaler和rank6先验冻结。每20步按固定VAL三噪声段clean MSE选权重，包含旧权重候选。世界目标用真实前向诊断，不冒称可微物理损失。无超参搜索。
4. 正式对照和执行：样条末步、旧Diffusion两步、旧Diffusion末步、新Diffusion末步。6 VAL+原冻结4 DEV，5种子/方法/任务=200候选；每候选最多110修正查询+3最终模型验收查询。修正器与所有门槛相同；两步法第一次最多74查询，为末步保留36。每任务方法只预选一条真实力矩执行及独立重放，最多40次。先完成VAL和方法选择，再写pre_DEV_freeze后运行DEV。
5. 证据审计和报告：核对任务/种子/源代码/checkpoint/预算/ctrl哈希/hold误差/重放及旧文件，回归测试、完成resume不重复工作、独立分支提交紧凑证据。收益阴性也完整报告。

## 冻结预算与判据

- CPU运行，诊断12、教师36、sanity80、训练240、正式候选200、预选执行<=40；整个后台运行墙钟1800秒。预计6—15分钟，实际以记录为准。
- 每候选同样5种子与最多113耦合查询；耗尽后保留失败，不补候选。不把查询数等同CPU成本，另报wall、物理步、网络调用和训练成本。
- C2同预算学习收益与相对样条必要性分别判断，均要求VAL和DEV满足20%查询节省及成功率/执行不降，候选wall不增加。没有额外收益时默认样条；推荐方案仅VAL决定，DEV验证。
- 5mm/1度、仅不穿透>=0、2mm几何细化、17→67、自由漂浮耦合、完整初态、全机几何、原力矩/动量/跟踪/重放门槛全部保留。
- DEV是多次开发的smoke，不是独立TEST。不得重标冻结失败目标；不得读取TEST数组、启pilot/study/strict_multimodal/生产任务。
- 不扩架构或大规模数据。若训练受阻，训练方法为BLOCKED，继续另外三组。进程中断保留已预留尝试，不重做未结算物理工作；训练中断依赖项BLOCKED。
