# 独立新世界目标验证：完整机制通过，网络直接命中仍不足

日期：2026-10-17。权威完成作业为 `artifacts/v7_1/independent_new_validation_recovery_001`，状态 FINISHED；原 `independent_new_validation_001` 的 FAILED、异常、账本和全部结果保留。本报告不改写已经冻结的协议或原始产物。

## 结论与当前目标

**Diffusion 加共同目标/碰撞修正、独立准入、真实67通道力矩执行与独立重放的完整机制，在这12个新开发任务上达到预注册稳定性门槛。新模型173/180候选合格、36/36选定执行及重放通过；相对强样条的预注册质量优势没有成立。** 网络直接到达世界目标的能力仍不足，完整方法的成功不能全部归因于网络。

按用户最新要求，优先顺序是：完整机制闭环 → 合格数据扩库 → 实际再训练与独立复核。时间和耦合查询只作预算核算及辅助诊断，不设相对胜出门槛，不围绕几个百分点成本差异追加实验。优越性继续实测，但不作为有限合格扩库的前置条件。

借鉴HTDCR的生成、精修、训练和引导分工。本项目保留两条数据路线：平滑运动经自由漂浮传播派生并冻结世界目标的主先验；固定世界目标下扰动、修正、独立准入的补充集。自由漂浮世界终点与运动路径有关，不能以相同关节终点代替相同世界目标。主先验不恢复同目标至少五条要求，strict_multimodal仍须另行满足原合同。

## 已实际完成的闭环

前一阶段 `qualified_coverage_train_001` 已用12144条TRAIN、原48条VAL完成6000次真实参数更新及384000次样本消费。11960项准确任务敏感度已核验；原冻结DEV四任务、三采样种子、四方法均60/60候选合格及12/12选定执行/重放通过。详见[训练报告](../../ff_prior_coverage_train/docs/ANALYSIS.md)。这项训练证据与本轮验证分开，本轮训练更新为0，没有选择新检查点。

本轮新增12个独立任务家族，包含6个新初态较大运动和6个新静态球障碍绕行任务。任务在所有方法运行前冻结，教师路径不提供给网络、公开初始化器或引导器。17次教师生成尝试中12项冻结、3项拒绝、2项兼容性异常，全部保留。跨既有TRAIN/VAL/DEV及仅作隔离保护的TEST元数据，目标近邻命中为0；没有读取TEST数组或执行最终TEST。

每方法12任务×3种子×5候选，共180候选；四方法共720候选。各候选采用相同公开初始化、16步DDIM（适用网络方法）及共同目标保持碰撞修正，预算15秒、113次耦合、15872个验证区间。每任务/种子在合格候选中按预定目标误差选择一条，真实执行一次，失败不替补。教师12条、选定144条均已实际执行并独立重放。

场景由冻结教师和公开直达筛选形成特定的困难开发分布，不能称自然随机场景或全域泛化。当前网络没有障碍条件，不能把共同物理引导的避障效果解释为网络学会不同绕行同伦。
