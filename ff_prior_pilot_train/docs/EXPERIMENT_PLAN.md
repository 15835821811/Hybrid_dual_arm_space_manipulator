# 10,000 条 pilot 数据的真实学习与冻结闭环：预注册协议

本协议在 qualified_pilot_001 仍生成数据时冻结；正式训练尚未运行。它承接已验证的1000条闭环及用户“机制可行后直接扩库”的授权，不以相对查询数或耗时优势作为推进门槛。

## 依赖与后台接续

队列只等待当前已确认存活的数据worker退出，不重启、不停止旧任务。等待上限7500秒。必须同时满足：数据作业FINISHED、实际进程退出、pilot_data_gate_passed及ready_for_training_stage为true、独立原始证据审计PASS、索引恰为10000 TRAIN及48 VAL且不含已知执行失败。否则保留失败原因，不启动训练。队列自身FINISHED仅表示成功启动训练，不代表训练完成。

队列冻结父run.json哈希和训练源码哈希。实际训练启动时再绑定已完成的数据数组、记录、初态、生成与执行证据、来源和预注册协议，保存源码快照。数据报告后来新增的分析文字不作为训练内容。旧数据、原冻结DEV、用户未提交修改、main及旧分支全部保留。

## 训练与实际消费

逐条读取10048条实际数组，构造公共初态/世界目标条件和公共初始化轨迹，不把教师终端关节答案作为推理条件。仅10000条TRAIN拟合时间基、归一化、条件均值和网络。VAL48保持原集合，仅记录诊断，梯度为零、不用于挑选检查点。

保留v预测、稳定DDIM实现、float64采样状态和float32网络。固定12000次优化更新，batch64、lr2e-4、seed20261081，目标局部耦合损失权重0.05；采用固定最终检查点。预计768000次样本消费，保存每条实际计数，并核验权重变化与检查点哈希。与1000条阶段训练长度和拟合表示可能不同，不能只归因于数据量。

每个不同TRAIN世界任务都建立其自身的34方向局部耦合敏感度，不用邻近VAL任务替代。容量从原1100扩展至11000，每锚点39次128网格耦合传播，保留半步差分和混合方向校验以及未覆盖时间方向的诊断。局部损失不是完整物理梯度，不能替代独立几何/目标验收。每个TRAIN行绑定准确task_hash的矩阵，矩阵按实际训练顺序校验哈希。

敏感度或训练受阻时相关新模型结果记BLOCKED，强样条和已验证1000条旧模型仍可执行独立对照，不用未训练模型充数。

## 冻结对照

原4个DEV任务不变，种子20261219/20261223/20261229，每方法每任务5候选。强样条、已验证1000条冻结Diffusion、10000条新均值、新Diffusion四方法，总240候选、至多48次选中执行与独立重放。新旧模型用各自与检查点绑定的codec。

公共初始化、物理修正器、每候选113耦合查询/15872积分区间/15秒上限一致，16步DDIM，目标保持碰撞引导位于最后去噪步。候选按最低归一化世界目标误差选择，只执行一次，不替补失败。保留全机不穿透、其他物理门槛、自由漂浮、完整初态及17→67映射；失败后不重标目标。

闭环门槛：所有10000条TRAIN确实消费；所有实际TRAIN任务敏感度合格；每个种子新Diffusion至少18/20候选合格且4任务均有合格候选；12/12选中执行及重放通过；候选数值和流程无ERROR；来源、实际数组、模型、采样调用、选择及原始trace审计PASS，无未知调用。相对效率优势不作为门槛。原DEV已多次用于开发，结论不能写成最终TEST泛化。

## 资源与结论边界

训练作业上限14400秒、2个CPU计算线程、40GiB新增输出；给独立对照预留1200秒。队列等待不计入这个活跃作业预算，队列另有限额。敏感度耗尽预算时停止新增锚点并保留依赖失败，不自动增加预算。

软件完成、全库实际训练消费、模型候选合格、选中物理执行通过、Diffusion相对收益分别报告。当前网络不直接编码障碍场景，碰撞处理仍由物理引导承担；不声称扩库自动产生场景泛化或独占优势。不运行最终TEST，不自动开始100000条或旧30000任务/150000候选生产。
