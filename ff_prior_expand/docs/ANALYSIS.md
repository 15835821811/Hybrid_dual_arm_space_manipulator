# 首批合格扩库与 Diffusion 完整闭环分析

本轮已经实际跑通“生成与独立准入→新增数据训练→条件Diffusion采样→去噪内目标保持碰撞引导→独立验证→真实力矩执行→独立重放”。首批扩库和冻结smoke通过，可进入已授权的有界pilot。它证明限定开发任务上的方法可行性，不证明神经方法优于所有对照。

## 实际数据与训练

759次真实提案新增744条合格TRAIN，15条因geometry门槛拒绝，未放宽约束、未重标失败目标。累计TRAIN为1000，VAL保持48；TRAIN家族标签由30增至284，其中254为新空场景家族。新增237条带既有外部障碍场景，共6个新静止零动量初态和3个原TRAIN障碍上下文。新增744个世界任务，但没有新增障碍场景，家族标签数量不等于统计独立性或绕行同伦类别。

新增控制点相对初态最大位移范围0.0404–0.4089rad；本批全部实际时长10秒。目标在256网格前向传播后冻结，再以独立256/512/必要1024网格验收。最大保存目标位置误差约6.40e-8m，最大几何步距1.98423mm，门槛2mm不变。保留完整初态、17→67映射、自由漂浮和全机几何。

实际读取1000 TRAIN及48 VAL数组，训练3600次更新，115200次样本抽取；新增744条每条均实际消费115–116次，权重变化与检查点哈希核验通过。912个TRAIN局部耦合敏感度锚点核验通过；归一化与基表示只拟合TRAIN，VAL梯度更新为零，使用固定最终检查点。新模型时间基rank6/潜变量102维，旧模型119维，训练步数也变化，因此不能把两者差异单独归因于数据数量。局部34方向目标损失不是完整精确物理梯度，也不替代独立验证。

继承12条旧记录的new_in_this_run字段相对于旧批次；本轮新增数以源路径、生成账本和expand_train_*样本ID确定。原输入字节保留，详见PROVENANCE_CLARIFICATION.md。

每个种子各方法20/20候选合格，任务、种子、候选数、预算与物理验收预先冻结；无执行失败替换。新旧Diffusion分别真实调用网络960次。16步DDIM的分解一致性与数值有限性均通过。这里是完整规划器成功，并非裸网络60/60直接通过：保存的引导内部初始归一化位姿误差各方法均大于1，全部经一次接受的目标保持修正后合格。该内部诊断不是完整的裸候选物理验收。

因此：当前主要闭合能力来自“提案＋物理修正＋独立验收”；本轮共同任务上各方法成功率均饱和，无法据此宣布Diffusion独占收益。查询与耗时仅保留在原账本作为辅助，不作为推进门槛，也不以小幅差异制造结论。

TRAIN碰撞机制对照复用了首轮兼容性错误退出前已真实完成的18个候选，模型、源码、任务、种子一致性已核验。相同原始网络提案下，开启碰撞引导9/9合格，仅目标引导8/9；唯一差异案例的无碰撞引导结果穿透约7.512mm。这支持该案例的碰撞引导作用，不证明普遍或神经网络独占优势。首轮KeyError及61.016秒保留并计入预算，没有重复运行。

## 真实执行与独立审计

原16条预选TRAIN参考执行及重放全部通过。原风险抽查存在按家族去重后漏掉最低障碍间距轨迹的局限，故另在新执行结果产生前冻结3条最低间距补充病例；3/3均通过。最小实际全机间距0.223264mm，目标保持误差均在原门槛内。补充仅升级对应3条的覆盖表，不改原记录。新增744条中共有19条拥有本轮执行及重放证据，其余725条仍仅MODEL_VALID；原父索引仍保留16个原执行标记，3条补充证据见单样本overlay，不能宣称全库已执行认证。

主审计重新读取64条执行及重放trace，核对672000物理步；补充3条核对31500步，合计67条、703500步（含独立重放）。审计本身没有新物理调用。主审计最大保持位置误差1.89395mm，最小间距8.46056mm；加入补充后最小间距为上述0.223264mm，勿混淆两个审计范围。

6443个历史文件、用户修改、main及旧分支和原DEV保持不变。保留TEST只读取目标元数据用于分区近邻拒绝；没有读取其轨迹数组、训练或评测TEST。完成后resume实测为NO_WORK_ALREADY_COMPLETE，两个输出目录原有6194/26个文件字节不变；该检查发生在添加本分析报告之前。
