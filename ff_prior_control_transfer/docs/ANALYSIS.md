**更接近同一教师控制轨迹，并不保证世界终点误差单调下降。** 这个样本的控制RMSE约降低93.6%，却从原目标合格变成不合格。该实测现象直接说明当前平均控制误差目标不能替代逐条世界目标验收。不能仅由这点确定是某个物理模型错误；映射敏感性、轨迹误差方向和多样本共享更新都可能参与，单次实验尚未分离其因果。
