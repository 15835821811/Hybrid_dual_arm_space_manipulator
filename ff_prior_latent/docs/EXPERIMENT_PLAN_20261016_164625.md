# 低维条件残差 Diffusion 实验计划

问题：上一轮自由漂浮全约束候选已稳定，但相对强样条仍多用7.38%查询、9.06%候选时间。不能把修正器收益归于网络。

## 主张与反证
C1：在同一实际预算内，直接学习TRAIN时间系数的条件扩散能改善合格候选或实际修正成本。
必须排除：收益仅来自确定性条件回归、额外物理查询、放宽约束或选取有利任务。
本轮为探索性开发验证；一轮结果不完成核心目标。扩库最终目标及完整完成标准沿用 ../..//ff_prior_feasible/docs/CORE_GOAL.md。

## 必跑实验
1. 软件门控：TRAIN-only拟合、系数重建、DDIM分解与最终双精度投影、任务冻结、后台重复启动保护；实际TRAIN物理回归覆盖原约束。
2. 学习：保留208 TRAIN/48 VAL原数据。只在TRAIN拟合7维左右时间基、条件ridge均值及缩放；v预测MLP在低维系数训练1800步，固定最后一步，无VAL选权重。新结构未加入障碍编码，其场景无关先验性质保持明确。
3. 配对对照：原10个VAL任务、5个原种子；强样条、旧600步冻结Diffusion、学习均值样条、低维Diffusion。均值样条第0候选用确定性均值，余4条加原0.03rad弓形扰动。强样条原实现不变。
4. 真实审计：每方法每任务从合格候选按原规则选1条，最多40次67力矩执行与独立重放。失败不重标世界目标、不替补执行。

## 预算与验收
新训练1800步、32 batch、2 CPU线程；最多200候选，每候选113次耦合传播、15872积分区间、15秒，整个作业3600秒。旧修正器、128完整路径引导与256→512→1024独立验证不变。
合格率每组≥90%、每任务≥4/5、执行10/10才满足稳定性。探索性Diffusion优势须同时优于强样条及学习均值样条：候选/执行不降，且更多执行任务成功，或实际查询与时间均至少减少10%。训练成本与推理成本分列。未测多训练种子，不作可复现最终优势声明。
最终判定依据是全机仅不穿透、5mm/1°世界目标、2mm几何采样以及原动力学约束。维度降低属于提案表示，不减少验收物理自由度。无pilot、study、TEST、扩库生产。

## 阶段与决策
M0 软件与输入身份审计 → M1 新模型真实训练 → M2 200候选及选中执行 → M3 原始证据复核、保留审计与中文报告。
若只均值有效，归因于条件回归，不能声称Diffusion必要；若低维方法仍弱，保留全部失败并转向固定TRAIN难例与条件覆盖诊断。稳定并有优势后才进入多种子复核及授权门控的扩库。
