# 强制核心目标：验证 Diffusion 优越性，并最终实现扩库

用户追加要求：2026-10-16。此文件是当前持续目标的补充验收依据；活动目标保持进行中。

## 必须同时完成的两项结果

1. **验证 Diffusion 的可复现优越性。** 以指定世界目标的自由漂浮双臂规划为对象，持续修复数据、表示、训练、采样与物理引导，在冻结任务、种子、候选数和计算预算下，与强样条及旧冻结模型比较。必须用真实结果证明至少一种有用优势：更高的难例任务成功率/覆盖率，或成功率不降时更低的实际计算成本。候选合格率、实际力矩执行、独立重放、误差与代价全部报告。
2. **最终实际扩库。** 形成可训练、可恢复生成、有质量分层和来源审计的扩展数据集，并用其实际完成训练与复核。扩库是必须交付的终局结果；不能仅交付扩库脚本、空索引、建议或一直停留在数百条样本。

两项必须同时完成。软件测试通过、单轮smoke结束、候选稳定或一次偶然独赢，都不能替代完整目标。若暂未证明优势或未完成扩库，持续目标保持进行中；具体受阻阶段保留BLOCKED证据，并继续独立可做的工作。不得为了满足预期而制造优势。

## 优越性验证的完成依据

正式确认前单独冻结协议；至少3组采样种子，并在可控预算下检查不同训练种子。保留全部任务、失败、正反向独赢和实际成本，不按结果临时更换指标。需要区分运动先验、目标修正、碰撞引导、新数据与新权重的贡献。

至少满足一种预注册的优势路径，并保持候选质量与物理成功不退化：

- 难例覆盖：在独立冻结的开发验证任务家族上提高任务成功率；同时报告样条独赢的反向案例和多种子一致性。
- 计算效率：在任务成功率与合格候选率不降时，实际耦合查询及候选墙钟耗时均降低；主张不能只依赖相同预算上限。

具体效应大小、任务数与统计标准在确认轮开始前冻结；本轮正在运行的协议不追溯修改。本项目最终TEST继续保留，当前证据明确标注开发验证范围。

## 参考项目及规模路线

已核对上传分析文件与[HTDCR项目](https://github.com/zhanglooong/htdcr-actuator-aware-diffusion-planning)。其[原始生成脚本](https://github.com/zhanglooong/htdcr-actuator-aware-diffusion-planning/blob/main/scripts/training/generate_training_data.py)配置10万起终构型对、每对5个模式，名义规模50万条；这是源码默认配置，不是已核验产量。[精修脚本](https://github.com/zhanglooong/htdcr-actuator-aware-diffusion-planning/blob/main/scripts/training/refine_training_data.py)另做驱动约束修正和独立可行性检查，默认入口只处理100任务，且不加载障碍环境。

借鉴其“轻量运动先验生成→约束修正→独立准入→学习→去噪内引导”的分工。保留本项目的自由漂浮耦合传播、前向派生世界目标、目标冻结、全机几何和分级真实物理审计；固定基座的关节终点逻辑不能直接替代世界目标约束。

长期规模目标定为 **10万量级合格先验**，按累计约 **1千→1万→10万** 分阶段推进。参考项目50万名义条目可作为后续容量参照，不能拿重复模式、失败条目或未验证候选填充合格数量。各阶段必须先冻结新增样本、独立任务家族、初态/目标/场景覆盖、物理抽查比例、计算与存储预算，再按实测准入率生成足量合格样本。

这些数量是扩库路线目标，尚未执行。当前仍只启动有界smoke及其允许的小批TRAIN补充；不会因写入终局规模就自动开启pilot、study、最终TEST、strict_multimodal或旧30,000任务/150,000候选生产。受限阶段须取得对应显式运行授权，已有范围内的实现与小规模验证继续推进。

## 扩库必须包含的内容

- 大主库：平滑样条提案、廉价筛选、自由漂浮传播、前向派生并冻结世界目标，独立验证后入MODEL_VALID库。主库不恢复“同目标至少五条”门槛。
- 难例修正子集：少量固定TRAIN世界目标，补充真正有效的绕行、较大运动及初态变化；根据消融决定是否引入障碍条件编码或保持场景无关先验＋物理引导。
- 分级物理证据：预先选定的分层子集做真实67力矩执行与独立重放，只有相应单条升级；未执行样本保持MODEL_VALID。
- 可用数据交付：实际数组、完整初态、17→67映射、模型/几何/约束版本、家族与分区、失败清单、来源哈希、验证等级、训练加载计数、覆盖统计和恢复状态。
- 训练复核：扩库后实际加载新增数据训练，并复跑冻结对照；数据更多不自动意味着收益成立。

## 始终保留的边界

仅不穿透与其他物理门槛不放宽；不固定基座，不在失败后重标目标，不泄漏DEV/TEST，不削弱样条基线，不增加Diffusion独享而未计费的预算，不把模型抽查批量升级为执行通过。

保留main、旧分支、旧数据、原冻结DEV、未提交修改和旧作业；不回退、不强推、不上传大规模数据。持续使用可恢复后台作业，终端可查，每轮保留源代码提交、原始证据和分析报告。
