# 有界 10,000 条 pilot：预注册分阶段协议

本轮用户已授权验证成功后直接 pilot；前置条件是 qualified_expansion_002 完成且 PILOT_ELIGIBLE=true、expansion_boundary_audit_001 全三例及独立审计通过、两个实际 worker 均退出。未满足时程序拒绝启动。本协议发布于新 pilot 生成和执行结果之前。

## 数据阶段

继承1000 TRAIN、48 VAL及原冻结DEV。新增9000合格TRAIN，最多14000提案、7000根家族；新空场景家族至少2500。12个新静止零动量初态，扰动幅度0.01至0.065rad；3个既有TRAIN障碍场景。每族2次提案、5种平滑形状；运动缩放1、0.75、1.25、1.5、0.5、1.75循环。此处不声称新障碍场景或绕行同伦覆盖。保留原固定时长选择集合和全部物理门槛。

轻量提案先廉价筛选，256网格自由漂浮传播派生世界目标并立即冻结，独立256/512/必要1024验证。失败不得重标目标。每条保存完整初态、实际数组、17→67物理合同、来源、家族、验证等级与失败账本。精确参考去重，并拒绝与VAL、原DEV、预留TEST目标元数据的近邻；不读取TEST轨迹，不评测TEST。

冻结48条执行审计名单：风险组24条首先包含全部15个上下文的最低模型间距样本，余下按全局最低间距补齐；随机组24条按上下文分层、样本哈希排序且与风险组不重合。允许同一家族的不同样本入风险组，避免遗漏边界案例。选择在执行前落盘，不因失败替换。48条分别真实67力矩执行及完整初态独立重放，仅通过的单条升级。已知执行失败从新训练索引排除，并保留失败记录。

资源上限7200秒、2计算线程、40GiB新增文件；生成预留900秒用于执行与核验，数量或预算到限即停，不无限补齐。后台可查、可恢复；中断未知调用不当作零，已预留提案不自动重做。旧数据、旧源码、原冻结DEV和用户修改不变。

## 数据阶段验收与后续闭环

累计至少10000合格TRAIN、2500新空场景家族、48/48执行及独立重放通过、保存数组与初态一致性及原始trace审计通过、无未知调用和ERROR，才标 ready_for_training_stage。数量达标本身不代表训练完成。

下一阶段必须实际加载新索引训练，保存逐条消费计数、TRAIN-only拟合与权重更新证据，再用原冻结DEV复核网络采样、目标保持碰撞引导、独立准入和真实执行闭环。数据阶段不运行新训练、不宣称Diffusion收益、不自动启动最终TEST。后续训练协议将在读取新训练结果前冻结；全目标仍进行中。

查询与时间作为预算及诊断记录，不要求相对样条效率胜出。对照优越性按实测另行报告，不修改物理门槛来制造优势。
