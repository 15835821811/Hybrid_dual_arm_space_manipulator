# 下一步有界验证：绝对世界终点监督与Diffusion实际贡献

日期：2026-10-20。状态：AUTHORIZED_READY。用户已授权按本有界协议实际执行；以下在运行前冻结。原256槽闭环已完成，旧结果与失败实验保留。

## 问题、主张与范围

问题：14222 TRAIN的新模型工程合格，但世界终点精度没有稳定改善，完整成功由共同物理引导支撑。下一轮固定数据，验证一个“绝对世界终点损失＋受控优化更新”组件，先证明能改善实际世界目标，再看完整Diffusion链是否比同预算简单方法更好。不再把库大小当首要自变量。

C1：在相同14222 TRAIN、旧13966起始权重、codec、6000批次/噪声序列及预算下，新增受控绝对终点监督能降低未修正生成的真实世界终点误差，且保持完整流程合格率。
C2：完整Diffusion链相对强样条与条件均值具有可观察的任务成功或世界终点质量收益。若四方法仍满成功且质量没有一致优势，明确C2不成立，收窄到可用生成先验，不继续反复调参。
反解释：新增数据、更多优化步、共同修正器、候选筛选或者改物理门带来表面收益。本轮不证明泛化到最终TEST、不证明裸网络无需验收、不证明硬件或连续时间安全。

## 已有证据支持哪些瓶颈

1. **学习的是教师附近相对误差，而不是绝对目标残差。** objective为v MSE + 0.05||G(x0_hat-x_teacher)||²；当预测等于教师，位姿项为0，即使教师实际世界终点仍有偏差。新增256条教师位置误差中位1.155747mm、最大3.361434mm，姿态中位0.105628°、最大0.264032°。合格不等于精度最优。原64父轨迹误差近0是前向派生目标的结果，不能把它当成已有逆向规划能力。
2. **G使用范围有限。** 原13495个教师锚的34方向近似映射到102维latent，新增同任务轨迹仍复用原锚。教师误差偏置没有进入旧loss；离锚更远时Jacobian精度是否下降未被本轮测定，不能断言已证实。
3. **修正器主要保证准入，存在停止精度。** 最坏四组归一化位姿范数≤0.65且间隙≥0.2mm时不再优化，相当于内部3.25mm/0.65°条件（最终准入仍5mm/1°）。旧模型最后一步179/180、新模型180/180没有调用局部求解；已可行情况下accept_update主要要求碰撞违约下降。故成功率饱和后，不承诺继续压低终点误差。这是代码和日志事实，尚非训练退化的唯一因果解释。
4. **新增覆盖与评价信号有限。** TRAIN仅+1.83%，64目标均已有，全库仍1578初态、13495任务锚。四方法180/180、36/36说明当前开发集在共同引导下不能再用成功率区分，不能当作Diffusion优势证据。
5. **历史真实世界loss有优化尺度问题证据。** 先前D组TRAIN损失比0.914改善，但位姿通过5/32→4/32；120世界事件全部clip，世界梯度中位约30.23、v约0.612、local约0.488。单步数值链通过不等于AdamW实际更新会改善。不能重新照搬固定0.1世界权重或删除local G；也不能据此归罪微重力。
6. **归因缺失。** 最新变化同时含补数据和6000更新。位置候选77对改善/103对变差，执行13/23；姿态有部分改善。这是混合变化，不是“模型完全无效”。网络未显式接收场景障碍特征，是未来复杂任务的潜在限制；本轮没有证据将其认定为现有误差主因，因此不同时改网络架构。

上述新只读统计见ff_prior_expand256_train/evidence/bottleneck_readonly_diagnostics.json；完整配对见final_statistics.json和新独立review。未为此重新仿真或训练。

## M1：用真实终点确认优化步可控（必做、仅TRAIN）

真实误差向量r按现有双臂世界位置/5mm、旋转/1°归一化，4个三维组。使用完整自由漂浮传播，在**当前预测**上计算全102维局部梯度；不会把教师锚线性项冒充真实当前预测。梯度网格用已验证路径，验收终点以512区间独立前向核对，保留原收敛检查。

世界目标定义为Lworld=max_g||r_g||² + 0.05*mean_g||r_g||²，优先最差位姿项，降低仅平方和允许分项相互抵消的问题。v与localG每批保留。世界梯度上限设为当次普通梯度范数的10%（分母极小时不注入，记SKIPPED），而不是沿用固定0.1乘以任意大世界梯度。全梯度clip1仍保留。记录各分项范数、角度、系数、clip、AdamW提出的实际参数增量及更新前后真实r。

24例只验证一次固定规则，不扫描权重。基于真实AdamW建议步，在固定比例1、0.5、0.25内检查世界事件样本与TRAIN控制样本；接受须最大归一化位姿误差下降、不把已满足的任一位姿组推到门外、无非有限值/域错误。拒绝世界试探则恢复试探前参数和优化器状态，不把它算世界监督成功。M1是独立诊断，不启动正式训练。这里是优化器信赖区控制，不是失败后重标任务或物理执行替补。

## 判定：有用、改善和优越性分别处理

1. **工程可用**：满足原工程门，世界监督和恢复账本完整。与科研增益分开，即使无增益也可以结束本轮。
2. **支持C1的最低证据**：无引导VAL中Q及位置/姿态分项报告完整；B在两个采样种子上Q中位数均低于A，位姿门命中数不减少；完整开发中候选/执行成功数不降低，执行位置平均误差和P95下降、姿态平均误差及P95不变差（仅数值容差，不给放宽百分比）。若只有原DEV4好而开发8退化，写局部改善，不写稳定提升。相对10%作为有意义改善的报告参考，不是进入下一步的强制门。
3. **C2必须直接对强基线**：成功率相同只说明持平。要称终点精度优势，需同时报告位置与姿态均值/P95及每任务配对，而非挑单一最坏值；若无法相对最强简单基线形成一致优势，C2=no/partial。180候选不当作180个独立任务，三个采样种子不当作三个训练种子。
4. **失败路由**：若B连无引导VAL都不改善，当前监督/优化尚未转为条件生成能力，保留A并结束；若无引导改善而完整链不改善，定位共同修正/选择的掩盖作用，未来单独预注册同预算精修机制；若两者改善但仍不胜简单方法，承认可用且提升，不强行认定Diffusion必要。只给后续建议，本轮不自动开启新实验。
