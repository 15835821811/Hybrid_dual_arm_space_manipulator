## 问题定位及证据边界

当前瓶颈集中在**网络提案的指定世界目标精度及其独立贡献**：完整引导流程成功率已饱和，不能继续用它来证明神经机制更强。新模型高噪声VAL完整轨迹RMSE在t500为0.028991rad、t999为0.033194rad，t0为0.000309rad；它说明高噪声重建仍有误差，但不是新出现的浮点异常，也不能单独解释世界目标误差。

6阶时间子空间的TRAIN最大控制点投影差0.000957rad，原10k之外3,774新TRAIN最大0.000126rad。这个表示诊断不足以证明世界终点精度，也不足以把问题直接归为时间基容量。局部位姿变化损失、条件分布、稀疏同目标样本及场景信息未直接进入神经条件，仍是有依据的后续研究方向；本轮没有做各因素独立消融，不能给出单一因果结论。

已有数据可用于训练，完整方法也有真实模拟执行证据。应缩窄当前支持的主张为“合格先验学习与共同物理修正构成稳定闭环”，继续独立记录网络收益。不能因多轮C2未通过而把实验改成直到胜出的无限搜索。
