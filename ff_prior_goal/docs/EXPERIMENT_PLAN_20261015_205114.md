# 世界目标约束采样：预登记 smoke 验证

## 问题与主张

目标：有效训练轨迹能够支持学习与采样稳定产生达到指定双末端世界目标的合格轨迹。
主张C1：完整耦合目标修正可使冻结Diffusion采样达到本次smoke内的稳定合格标准。
附加主张C2：学习先验带来超过相同修正机制下普通样条的收益。C2必须独立实测，不因C1通过自动成立。
反解释：成功可能全部来自目标修正器，而非网络；平滑也可能单独改善几何而未解决目标。

## 冻结方法

- 沿用fixed_train_consistency_001已训练的166 TRAIN网络、TRAIN scaler和rank6先验，不改权重或重训。
- 三方法：普通平滑随机提案+目标修正；Diffusion+目标修正；Diffusion仅相同曲率平滑。
- 曲率平滑最小化控制点偏移加10倍二阶差分平方，保留前三个初态和后三个提案终态控制点。
- 目标修正：17个平滑方向，完整自由漂浮路径传播128区间求12维双末端位姿残差与有限差分雅可比；阻尼1e-3，差分1e-4rad，参数步长不超过0.1rad，固定四档回溯；每次最多4迭代。
- Diffusion每候选16步，仅最后两步对clean estimate平滑及修正；修正后重新计算epsilon，保持float64状态及最终物理提案，复用已测试DDIM。
- 结构基线也执行相同两次修正；消融只去除目标修正。禁止给规划器训练/DEV私有终端见证。
- 终端修正目标1mm/0.2度仅为内部停止标准；正式门槛仍5mm/1度和原全部MODEL/EXECUTION门槛。没有固定基座、改变目标或放宽非穿透>=0m、2mm几何细化。

## 实验块与顺序

1. M0：原16条固定TRAIN修正标签重新通过完整模型和世界目标检查；软件测试覆盖非零可达目标、不可达目标不重标、实际checkpoint/DDIM和后台锁。
2. M1：VAL原6个family各选哈希固定的一目标，每方法每任务5候选。所有参数在运行前冻结，不使用VAL进行这轮参数搜索。
3. M2：原4个冻结DEV，每方法每任务原5候选和原种子20261017+任务索引*101+候选索引*997。VAL种子起点20261023。DEV不用于训练或选择配置。
4. M3：每组每任务每方法按最低归一化目标误差预选一个合格候选；真实MuJoCo力矩执行及独立控制重放，无执行失败替换。基线与Diffusion均执行。
5. M4：自动报告、逐候选成本及失败分析、只读证据审计和完成后resume不重复工作验证。

## 预算与验收

总16次标签检查；150个候选；两种Diffusion合计1600网络调用；最多30次预选执行与30次独立重放；1800秒总wall。没有pilot、TEST、study、strict_multimodal或生产开关。所有探针/迭代计费，修正成本不可隐去。
C1通过要求：每个分组投影Diffusion合格率>=95%，每任务>=4/5合格，10个任务的选定执行与重放全部通过。该标准仅用于本次smoke，不能支持全工作空间或独立TEST泛化。
C2报告同修正机制的任务成功、候选合格率、位置/姿态误差、耦合查询和wall；只有真实证据支持时才讨论额外收益。
若负结果：保留失败与原冻结协议，后续更改必须新版本/新输出记录，不覆盖本轮、不暗中增加候选。

## 风险

局部雅可比投影不保证非凸可行性；所有返回提案仍经过全机几何和力矩门槛。曲率正则可能改变世界目标，必须在正则之后执行耦合目标修正。只有VAL/DEV少量开发任务，不能自动升级未执行样本或宣称硬件准确。
