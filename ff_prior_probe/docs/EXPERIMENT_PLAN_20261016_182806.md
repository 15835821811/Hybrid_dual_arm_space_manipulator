# TRAIN残差幅度机制：冻结实验计划

**问题**：上一轮目标损失将查询2250降至1735，但同数据均值仍为1710；需判断随机性是否带来有用的合格轨迹变化，还是主要增加目标修正负担。
**主方法命题**：对相同已训练网络的同种子提案，仅改变相对同一个学习均值的残差幅度，可以分离目标损失和采样幅度作用。
**范围**：有界smoke机制诊断；不是study配置，不训练新模型，不新增数据，不运行VAL、原DEV或TEST。完整可复现优势与实际扩库目标不缩减。

## 主张与反证
| 主张 | 最少证据 | 反证 |
|---|---|---|
| C1 减少残差可降低指定世界目标修正成本 | 同一网络/种子未缩放提案一致，按幅度统一缩放，共同物理修正和门槛，实际查询与时间下降 | 只有缩小输出、损失多样性而无独立收益；不能称为学到更好分布 |
| C2 某衰减幅度保留可用变化并节约成本 | 相对同网络完整幅度，合格数不降、稳定门槛通过，查询及时间各降≥10%，合格两两RMS均值和不同轨迹总数均保留≥80% | 均值重复、仅坐标离散、没有不同可行路线；不能证明多模态或泛化 |

## 实验块
1. 软件与真实TRAIN回归：确认幅度0/1精确等于均值/原输出，DDIM16次调用且分解数值一致，实际自由漂浮候选仍满足原门槛；旧测试隔离输出。
2. 配对TRAIN诊断：使用qualified_modes_smoke_001的全部8个生成父任务，5个原TRAIN家族，移除推理入口中的源标签控制点；任务与世界目标不改。
3. 真实执行：预选任务槽0（外加障碍）与6（初态变化），每方法每任务只执行最低归一化目标误差的合格候选一次并独立重放，失败不替补。其余六任务仅MODEL_VALID候选证据，不批量升级。
4. 原始审计与归因：核验每组三个幅度确实来自同种子同网络的完全相同未缩放输出；失败、全部成本、配对胜负、原始/最终多样性一并保留，形成中文报告。

## 方法和计费
十个设置属于结构基线、学习均值、Diffusion三类：强样条；上轮冻结低维模型；新数据学习均值加原0.03rad弓形扰动（第0候选为精确均值）；精确均值零残差；普通模型残差0.25/0.5/1；目标损失模型残差0.25/0.5/1。
两个新模型仍用上轮固定检查点。本轮没有新的训练/检查点选择。每方法每任务5候选；种子20261113+任务序号*101+候选序号*997。每个候选块轮换方法顺序，全部采样独立实际运行，不使用跨方法缓存免除模型调用或计时。零残差5个重复候选全部计费，最多算一个不同路径，不能虚增覆盖。
每候选113耦合查询、15872积分区间、15秒；共同修正器110查询和独立验证最多3查询，不新增未计费传播。修正前位姿误差取共同修正器第一次数值传播，定义为共同平滑/边界处理之后、迭代修正之前。完整未缩放输出、幅度缩放输出和最终控制点均保存。

## 判断标准
每方法稳定门槛：至少36/40候选合格，每任务至少4/5，预选执行与重放2/2。只有当同网络完整幅度和衰减设置均稳定，且满足C2所有条件时，标记TRAIN衰减机制信号。合格轨迹差异按候选序号贪心RMS≥0.005rad计数，同时统计每任务两两RMS再均值；该度量不认证不同同伦类。
没有任何本轮结果可单独宣布Diffusion整体优越。若精确均值成本最低且衰减损失变化，应研究保持目标的残差/去噪约束。若出现保留变化的降成本信号，只作为后续参数候选，下一轮仍需独立开发家族、至少3组采样种子与不同训练种子确认，保留最强均值及样条。不得追溯改变本轮标准或按结果剔除任务。
