## 5. 工作包 P1：建立能区分路线价值的配对任务

### 5.1 只研究一个任务族

“连续体末端在允许区间内绕行；刚性臂继续原目标任务”。不声称新增了连续体全臂主动形状规划。

每对 c+ / c-：

- 初始机器人状态、任务锚点/窗口、目标运动、时长和障碍尺寸相同。
- 只将一个已有工作空间球障碍放在基础参考中段的横向两侧。
- 不移动锚点、不增加路线方向标签、不把某个固定左/右方向写进 Task 成功条件。
- 其余几何与约束不变。两臂不对称，不从一个场景镜像重用实际轨迹或成功标签，两个任务分别执行。

障碍位置必须由冻结的几何生成规则确定，而非根据 Diffusion 结果挑选。可以先进行低成本参考/几何检查排除初态穿透或锚点本身不可达；这些不是完整可执行性证明。

### 5.2 开发 pilot 固定六次尝试

一对任务，每任务固定：z0、z+、z-。

- z0：零残差。
- z+ / z-：在预声明区间沿第一横向基 ±12 mm，其余系数零；如现有区间无此表达能力，记录原因而不是改变锚点或幅值上限。
- 共 2×3=6 个 actual slot，不追加位置搜索或候选重试。

### 5.3 “路线价值”判据

所有比较先要求完整 Task 和原独立安全检查通过。失败前缀不与完整轨迹计算同一平均路径代价。

对于完成的运行，定义固定路线作用窗口 T_route 上的控制干预：

I_route = sqrt(mean(||u_unconstrained(t)-u_selected(t)||²)), t∈T_route。

T_route 由任务允许的残差区间预先确定，不根据表现挑时间窗口。明确这些向量是 QP 无约束名义速度与实际选择速度，不是 raw proposal 与 selected 的差。复用旧诊断定义；存在源向量缺失则披露 producer 字段范围，若需新增源向量日志，应先做小型数值不变检查，不更改控制行为。

另报相同窗口内相关 continuum-obstacle pair 的实际净空、连续体路径长度、基座扰动和全任务安全指标。不能用 rigid-target 主导的整机最小值宣称绕障收益。

pilot 判断任务具有区分力的情况：

A. 一条非零路线完整成功，另一方向或 z0 失败；或者
B. 都完整成功，但某一非零方向相对 z0/相反方向的 I_route 降低至少 10%，且绝对差至少 0.001 rad/s。

10% 和 0.001 rad/s 是本轮质量可辨识性门槛，不是物理安全阈值。两侧任务应出现相反方向的有利变化，才支持学习“依场景选方向”。不得要求 Diffusion 优于其他方法才接受场景。

### 5.4 pilot 的停止条件

若六次尝试无法显示路线区分力：

- 保存全部结果为 ROUTE_VALUE_NOT_IDENTIFIABLE_WITHIN_CURRENT_REPRESENTATION。
- 不训练第二个模型，不通过扩大 20 mm 或改变目标反复寻找正结果。
- 给出是哪一种限制：障碍未影响关键区间、所有路线同质、残差表达不足，或没有非学习可执行性见证。
- 本次有限研究可以负结果结束；不得称 Diffusion 被否定。

若通过，继续 P2。pilot 两任务只用于开发，不入正式 TRAIN/VAL/TEST。

## 6. 工作包 P2：用闭环质量差异构造示范，而非收集任意成功扰动

### 6.1 数据协议

正式数据固定：

- TRAIN：3 对 / 6 个任务。
- VAL：1 对 / 2 个任务。
- TEST：2 对 / 4 个任务。

在训练和生成模型 TEST 候选前冻结任务与分组。一个配对及其近重复母场景必须整体属于同一 split，不能把同一母场景的镜像、重采样或微小扰动拆到 TRAIN 和 TEST。

TRAIN/VAL/TEST 可在预声明参考区段和障碍偏置尺度上变化，但不能同时增加速度压力或惯量变化。只有很少的独立母场景时，明确标记局部迁移先导，不冒称广泛泛化。

### 6.2 固定 teacher 库

每个 TRAIN/VAL 任务仅四个候选：

1. z0：零残差。
2. z+：关键区间第一横向基 +12 mm。
3. z-：关键区间第一横向基 -12 mm。
4. z_perp：同区间第二横向基 +10 mm。

关键区间和基向量由同一任务规则生成，不看实际成功后再调整。所有幅值服从原 20 mm 门槛。

8×4=32 个 teacher actual slot。预检拒绝也占 slot，不补抽样；真正发生物理步的 actual 数另报。

### 6.3 标签必须包含任务内比较信息

对每条完整成功且安全证据齐全的参考记录：

- z（实际送入 provider 的输入，不拟合 actual q）；
- 完整任务、执行与几何结果；
- I_route、总路径长度、相关几何余量；
- 所有拒绝/未完成状态；
- 任务内路线排序与方向标签，方向标签只用于训练数据分析/评价，不能作为测试输入。

按预声明规则形成 quality-filtered 成功标签：

I_min = 该任务完整成功候选中的最小 I_route。
允许进入高质量集合的候选需满足
I_route <= I_min + max(0.1*I_min, 0.001 rad/s)。

同一集合内保留多条真实有用路线，不先求坐标均值；不强制排除零残差，零残差确实最好时它就是合法答案。

路径长度作为次级描述和同质量层内的 tie-break，不能在看到 TEST 后调目标权重。失败案例只用于标签/失败分析，不作为成功去噪标签。

比较含义是“在这四个预声明 teacher 候选中的较优参考”，不是全局最优轨迹。

### 6.4 数据资格

优先检查每个任务是否拥有可用高质量示范、几何换边是否带来不同路线偏好。

不以反复暴露凑成独立轨迹数。若不足四个 TRAIN 任务拥有可用标签，或 VAL 没有支持评价的标签，标记 DATA_INSUFFICIENT_FOR_THIS_PILOT；保留32次预算，不追加示范。

本轮不是通过仅增加更新次数继续训练旧17条通用扰动，而是有意识地改变示范的任务信息和质量定义。

## 7. 工作包 P3：保持网络不变，只训练一次任务条件先验

### 7.1 模型

- 保留 12 维残差、原两层128 MLP、原条件布局与 mask。
- 不新增 learned critic、不端到端反传 MuJoCo/QP、不新增成本梯度引导。
- 复用已核实的噪声过程与 DDIM20。
- 新训练输出独立 checkpoint；旧 B.2 权重不覆盖。
- TRAIN scaler 重拟合，仅使用 TRAIN，并对所有后续模型/检索/经验采样一致应用。

新任务几何相关条件的语义必须与旧编码器一致；如需修复条件接线错误，单独标记为实现修复，不宣称网络创新。

### 7.2 预算

单 seed，batch32，最多4,000次 optimizer update，一次主训练；无参数搜索、追加 seed 或 TEST 后续训。

去噪损失采用已有定义。训练样本来自 P2 的高质量参考集合，按任务均衡采样；记录每个独立参考的曝光次数。

### 7.3 checkpoint 选择

保留原固定验证 seed，并在 plan 中先固定选择规则。

建议每250次更新保存一次：

1. VAL 参考合法性优先；
2. 合法输出到该 VAL 任务已验证高质量参考集合的解码路线距离，越小越好；
3. 同分再按固定 VAL 去噪损失；仍同分选较早更新。

每个 VAL 任务固定4组噪声，不执行新的物理 VAL rollout。集合距离在相同材料/任务时间网格上比较解析残差路线，不能把多个不同绕行模式求均值当目标。

非法幅值不得静默裁剪；它在第一项计失败。选择规则和全部 checkpoint 曲线保留，不按 TEST 完成率重选。

这种选择使用的是有限 teacher 集合，并非验证全局最优；报告要披露相对于旧 B.2 checkpoint 规则的改变，不能做严格单因素跨轮归因。

5组×4任务=20个TEST actual slot。全部尝试；禁止失败后换候选、换种子、换模型或fallback。

### 8.3 TEST可执行性

Z0/R0成功可为相应任务提供非学习见证；若二者都失败，保持 TASK_FEASIBILITY_NOT_ESTABLISHED，不能由此推出任务物理不可行。

## 9. 评价口径与决策

### 9.1 功能指标

- 各组完整27s且全部独立门禁通过的任务数/4。
- 预检、执行拒绝、未完成原因。
- raw合法率及有用多样性；不同数值不是不同路线拓扑。
- D_true/D_swap固定噪声下的条件响应，报告方向/幅值，不把任意变化称正确。

### 9.2 质量指标

只在两方法同任务都完整成功时比较：

- 固定路线窗口I_route（主要质量指标）；
- 全任务干预RMS；
- 连续体实际路径长度；
- 相关continuum-obstacle局部及全时域最小净空；
- 整机门槛、基座扰动和终端/锚点误差。

始终同时报告全部任务失败，不能只比较D_true恰好成功的容易任务。对失败前缀的路径/干预保留独立描述，不填入完整平均表。

### 9.3 计时

统一测量Z0构造、R0检索、U0抽样、D_true/D_swap加载/条件编码/采样/解码/预检的分项及端到端耗时。准备/首次加载/稳态分别报告，嵌套计时不相加。20ms墙钟不作研究门槛。

### 9.4 可支持的结论等级

A. D_true改变实际动作且可执行：生成与执行贡献。
B. D_true对真实障碍条件的路线选择优于D_swap，并相对U0有一致收益：局部条件价值证据。
C. D_true相对R0有同任务成功/主要质量收益，且未降低声明安全/任务满足：有限先导方法优势线索。
D. D_true/D_swap/U0相近或R0仍最好：保留非学习方法，不追加预算追正结果。

四个TEST和一次训练不提供总体统计优劣保证。不要把一个小p值、单场景最好值或解析锚点通过率替代完整证据。

至少将以下状态分开：

research_delivery_complete
route_value_identifiable
training_executed
condition_response_observed
conditional_value_supported_in_pilot
advantage_over_retrieval
independent_test_task_success_by_method
deployment=NOT_MET

## 12. 最终执行指令

从当前已封存B.2继续，先用一对六次实际对照建立有区分度的路线选择问题，再用固定teacher预算生成真正与障碍条件相关的高质量示范；不改网络和控制器，只训练一次新先验。最后在四个冻结任务上同时比较零残差、检索、无条件经验采样、正确条件Diffusion和错配障碍条件Diffusion。

不把目标设成“必须赢”。目标是取得可信的条件路线选择证据，或在固定预算内否定该假设。正确条件不能产生价值时，保留检索，不靠多候选全仿真筛选、追加种子或控制修复改写结论。

## 13. 方法背景（不作为本项目实验结果）

- Carvalho 等，Motion Planning Diffusion: Learning and Adapting Robot Motion Planning with Diffusion Models，arXiv:2412.19948。区分学习轨迹先验与结合任务代价的规划。
- Janner 等，Planning with Diffusion for Flexible Behavior Synthesis，ICML 2022，PMLR 162。将扩散轨迹分布与目标引导结合。

本轮仅吸收“可行先验不自动等于有价值决策”的设计区分；不直接移植论文的成功率、机器人安全结论或增加其成本引导模块。
结束后把当前版本作为单独分支上传github，并且把该分支下的所有可视化刷新。
