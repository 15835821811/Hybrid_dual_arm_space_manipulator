## 4. T1：新增提前平台型 C² 参考，不改残差维度

保留原 v1：

    phi(u) = 64*u^3*(1-u)^3,  u in [0,1]

新增独立 v2：同一合法区间 [a,b]，默认比例 r=0.25、f=0.75。
令 S(v)=10*v^3-15*v^4+6*v^5。

    psi(u) = S(u/r),                         0 <= u < r
             1,                             r <= u <= f
             S((1-u)/(1-f)),                 f < u <= 1
             0,                             otherwise

同一段使用 delta_p = E*z*psi(u)，E 为原固定世界横向基。
速度和加速度分别使用 psi'/(b-a)、psi''/(b-a)^2；不得只修改位置。

目的：在靠近障碍以前建立偏置，并在关键时段保持；不是承诺必然产生收益。

要求：
- a、b 使用原合法 reference-time 区间，不跨保护窗口。
- 起止点和各拼接处 C² 一致；保护时段残差为零。
- 刚性臂参考与连续体姿态不变；目标按物理时间运动。
- 不在实际执行中改变 E，也不引入未建模的基座随动导数。
- v2 的速度/加速度可能比 v1 更大，必须先经过原参考检查；不合法则拒绝，不放宽限值。
- 在新 reference version / hash / 绑定字段中明确记录 v1/v2；不能把 v2 当成原 v1。
- 零残差尽量直接沿用旧 provider 数值路径。

必要测试仅包括：零残差一致性、分段连接处 p/v/a、解析导数对照、保护窗口、范数限制、实际消费字段与版本绑定。

## 5. T2：冻结 2 个障碍偏移级别 × 两侧 × 七个参考模式

保持旧 B.3 pilot 的母场景、初态、锚点、目标运动、球半径及其余障碍。

场景级别：
- d=43 mm：原 B.3 pilot 正负侧，来源可完全对应时复用原 v1 结果。
- d=55 mm：新开发级别，只修改该球中心的横向偏移。

55 mm 是本补充预声明的设计参数，不是已经验证过的可行位置，也不是“更简单就可以算 Diffusion 成功”。其用途是测试较小的所需避让是否落入 20 mm 参考权限；必须保留这个分布变化。

每级别均为：

    sphere_center = base_reference(midpoint) + side*d*E[:,0]

仅使用声明参考/初始模型生成几何；不使用未来测试 actual。
只做固定的初态、锚点与原参考合法性检查。检查失败也保留场景和槽位，不继续搜索其他位置。

每个任务固定七种参考：
1. z0（零残差，一次即可）
2. v1，关键区间第一横向 +12 mm
3. v1，关键区间第一横向 -12 mm
4. v2，关键区间第一横向 +12 mm
5. v2，关键区间第一横向 -12 mm
6. v2，关键区间第一横向 +20 mm
7. v2，关键区间第一横向 -20 mm

共 4*7=28 个槽位上限。旧来源能严格匹配的结果允许原件复用并注明，复用不是新 actual。拒绝占用槽位，不补候选。每条新运行从真实初态执行 27 s 或由原门禁拒绝。

这是开发数据与教师参数研究，不是独立泛化 TEST。原未执行 B.3 TEST 不得悄悄并入本轮训练。

## 7. T3：教师排序依据真实闭环结果

先按原完整 Task 和全部安全/执行门禁判断资格。
完整失败、预检拒绝、执行拒绝不与成功轨迹混算路径均值。

保留原 I_route：固定关键区间的 17D 裁剪名义速度到选中速度范数 RMS。
它是全部约束共同作用的诊断，不命名为单球障碍专属干预。

同时记录：
- I_route 的连续体/刚性分量（新向量可得时）；
- 相关连续体—球净空及对应 witness、时刻；
- 相关球约束激活/绑定持续时间；
- 连续体全程及路线窗口路径长度；
- 位姿任务误差、基座漂移、力矩饱和与完整成本；
- 参考偏置到实际偏置的全窗口响应。

固定有限教师选择规则：
1. 必须完整 Task 且安全验证通过；
2. 用原 I_route 从低到高排序；
3. 数值近似并列时按固定 tie-band 标记为不可区分，而非强行生成高置信度偏好；
4. 固定 tie-break 使用路径长度、系数范数、候选 ID；并报告代价冲突，不能只发布优胜者。

tie-band 在新 actual 前冻结：不得用新测试结果倒推阈值。该参数是开发偏好解释，不改安全标准。

必须同时显示原 B.3 10%/0.001 rad/s 标准是否达到。即便新协议使用有限候选后悔值作补充，也不能将旧 2.79%/3.81% 重判为原通过。

建议保存质量向量，而不是只存 winner：Task 状态、I_route、路径、净空、幅值、约束活动和版本。之后才能判断是否有多条近优参考，而不是反复学三个固定标签。

## 8. 必须计算的价值上限与比较

在每个任务有限成功候选集合中报告：
- 零残差代价；
- 最佳固定正模式、最佳固定负模式；
- 简单几何规则（选远离球中心侧）的结果；
- 有限 teacher 最低代价；
- v1/v2 在同任务同 z 下的差异。

跨任务报告：

    V_cond = min_z mean_c J(z,c) - mean_c min_z J(z,c)

只有在参与比较的候选均有完整可比结果时，直接计算数值；有失败时先分别报告成功率与共同完成子集，不随意填一个成本参与平均。

该量只是固定候选集合、固定任务上的离线条件选择潜力，不是已实现的 policy，也不是连续空间的最优值或统计保证。

不能只比较最差固定方向；零残差、几何规则和最佳常量均应出现。
