## 结果实际支持什么

1. **可观测初态一致，但完整历史状态未恢复。** initial_state 中重建初始化与选定旧 trace 首帧的 qpos、qvel、q17、dq17 最大绝对误差均为 0。836 维、mask=8191 的 integration state 往返误差为 0，只证明本次候选状态的存取一致。它是当前保存代码生成的重建候选，不是历史归档原件；ctrl=0、极小 warmstart 等是候选值。44 个候选 source_snapshot 的四文件合成 hash 均未匹配该旧运行记录，无法据此绑定历史代码。

2. **物理 spec 的部分不变量一致，完整执行合同不同。** 三个 runtime/spec hash 相同，67×17 映射差为 0，力矩限值差为 0。连续臂规划域由旧重建环境的 ±π 变为当前适配器的 ±1，接触参与几何数由 0 变为 78，因此 spec hash 相同不能推出执行合同等价。“旧环境”在这里是当前代码构造的旧接口环境，不是已找回的原版本二进制或快照。碰撞对数 2927 与 2860 来自含两障碍场景和裸机器人，不能归因为策略变化或判定配对集合等价。

3. **相同 trace 确有标签冲突，应隔离。** 两份 trace 的独立 hash 一致；早期记录 admit=true 且 execution 缺少运动限值检查字段，后期 admit=false，记载最大实际加速度比 1.0602421738086565、joint_limit_violation_steps=18。早期 true 不能覆盖后期失败记录。本轮没有重新计算 500 Hz 加速度峰值；18 是记录字段所称违规步数，不能未经重算细分为 18 个纯加速度违规事件。“后来补齐检查”是字段差异支持的解释，尚不是历史执行过程的独立重建。

4. **本次检查的记录无静止覆盖。** stationary_search 包含 581 个记录条目：528 TRAIN、53 validation；按原生目标自由关节速度地址 `[73:79]` 和阈值 1e-12，静止计数为 0。记录中的线速度最大分量下界约 0.00100717，角速度最大分量下界约 0.0000218777，二者均非零。这里是记录条目数，不是经独立去重的 581 条唯一任务。五份目录元数据清单未提供新的已分割静止来源，不能把未分割 baseline、DEV 或静态终点样本转成静止 TRAIN。

5. **停止下游符合协议。** summary 的 representation_execution、training、DEV 均为 BLOCKED，训练更新和新物理步为 0；代码路径也没有调用整段控制器执行。preservation 报告清单内 802 文件未变。这支持本次受限诊断没有放行下游，而不是证明数据当前可执行。

## 遗漏、措辞和证据边界

- 预抓取目标定义还存在 `-0.205 m` 对 `-0.235 m` 的局部偏移差。worker 中当前 DEV 值是硬编码常量，不能称作本轮从 DEV 实际配置独立读取验证；它至少说明目标语义也必须在资格复核前明确。
- freeze 未绑定直接使用的 `ff_prior/robot_adapter.py`、`ff_prior/geometry.py`，也未完整绑定所有传递依赖和运行时版本。802 文件未变应表述为“冻结清单内未变”，不能表述为所有模型、执行依赖和软件环境已完全冻结。本审查未再次对 802 文件全量计算 hash。
- 静止检查依赖上一轮 episodes 清单、统一原生模型地址和当前保存模型结构；没有逐记录证明各历史编译模型地址完全相同。若后来发现异构模型来源，需按其模型合同重新解析地址。该限制不构成当前已有静止数据的正面证据。
- 目录补查是指定根下四种文件名的有界发现，不等于对所有磁盘、任意命名数据或未登记来源的穷尽证明。可说“检查范围内未找到合格静止来源”，不可说“任何静止数据都不存在”。
- 缺失历史完整 integration state、历史 ctrl 和精确源快照限制的是**历史精确复现**。它们不是逻辑上永久禁止当前 MODEL_VALID 的理由。一个明确披露来源的新完整初态，可以通过当前合同的新资格审查获得当前有效性；但不能借此改写旧失败标签或宣称复现了原历史运行。
- “缺少历史 500 Hz torque trace”不能独立解释所有加速度峰值不可复算情形；精确复算还涉及高频状态、加速度定义与统计口径、代码和完整初态。现有结论应保持为“本轮只引用历史统计，未独立复算”。

## 不支持的主张

不支持历史完整状态已精确恢复、已找回原运行代码、当前/旧合同等价、当前执行安全通过、旧失败已消除、581 条记录全部合格、静止覆盖满足要求或训练/DEV 收益。没有训练对比结果，不能提出性能提升主张。
