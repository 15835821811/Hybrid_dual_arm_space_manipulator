## 目前的瓶颈与下一阶段判断

1. **单换主干没有解决指定目标条件精度。** Transformer学习到的提案在引导后有较低残差，但无引导全部目标门仍失败。注意力、残差和归一化一起变化，不能把改善单独归功于注意力，也不能由本轮否定其他Transformer结构。
2. **训练目标和完整采样验收仍有距离。** 当前损失是噪声时间点上的v去噪加教师附近局部G；不直接约束完整16步DDIM输出经过自由漂浮传播后的最终世界位姿。本轮故意保持相同损失以隔离主干比较，因此不能声称本轮验证了新的非线性世界监督。训练与采样目标对齐不足是值得下一轮检验的机制假设，不是本轮已证明的唯一原因。
3. **从头6000步与旧温启动模型不可混为一谈。** 两个新神经主干从头训练，旧模型的累计训练经历不同。旧报告的无引导命中数不能直接与本轮比较后归因于架构，更不能把本轮0/96说成旧生产模型退化。
4. **这组DEV成功率已饱和。** 四方法都180/180与36/36，通过率无法区分能力上限。本轮允许比较终点残差与失败尾部，但不能证明解决了样条失败的任务，或获得最终TEST泛化收益。

建议本轮完成后保留MLP旧默认交付链，Transformer作为可用实验候选保留，暂不以这次残差改善自动替换默认模型或继续扩库。工程全流程已经跑通，可以交付合格的“先验＋物理引导＋执行重放”轨迹；不需要先证明Transformer普遍更优才承认流程可用。
