# 新初态覆盖实际训练与完整Diffusion机制验证协议

## 目的和优先级

按用户最新目标执行：先把合格数据生成、学习、稳定采样、目标保持碰撞引导、真实力矩执行与独立重放全流程跑通，再持续合格扩库。借鉴HTDCR生成、精修、训练、引导分工；本项目保留自由漂浮路径依赖的双末端指定世界目标。相对耗时和耦合查询不设胜出门槛，仅资源核算。仅不穿透和其他物理门不变。

新数据源qualified_origin_fill_001实际FINISHED/merged gate PASS；原qualified_origin_coverage_001仍BLOCKED/ready=false/39ERROR。新合并库12688 TRAIN/48旧VAL，555种TRAIN初态。新覆盖544条按两个producer_run_id识别，不能按new_in_this_run误取9条；其中33执行等级、511 MODEL_VALID，等级不变。

## 两个预先声明的主张

C1：新合格覆盖实际用于学习，完整Diffusion规划器在原DEV回归及独立NEW_VAL稳定完成指定世界目标并真实执行重放。证据包括逐行抽样、权重改变/重载、精确敏感度、同预算采样和原始执行审计。

C2：新模型提供强样条及更新条件均值无法等价替代的目标提案质量。成功率饱和不能单独证明NN价值；必须报告raw、共同平滑限位后、修正后的质量。本阶段不是数据量单因素因果实验，也不声称全域/硬件/最终TEST泛化。

## 冻结设置

- 数据：12688 TRAIN（旧12144+覆盖544）、原VAL48；NEW_VAL8在之前TRAIN生成前已冻结，不进入梯度、codec/mean拟合或检查点选择。原DEV4逐任务保留。本组NEW_VAL若后续用于调参将标为DEV。
- 接续：温启动已验证12144模型，原10000 TRAIN拟合的codec/时间基/中心/缩放固定；新AdamW，lr2e-4，seed20261901，6000更新×64=384000真实样本消费。独立打乱穷尽队列，每批旧32+覆盖32，各192000；保存RNG/队列/优化器/逐行计数。无VAL梯度或检查点选择，固定最终更新。
- 损失：稳定v预测+.05局部34方向自由漂浮耦合位姿变化MSE；保持旧公式。它是沿17终端+17零终端弓方向的局部代理，不是完整latent梯度或完整非线性指定目标零损失。
- 敏感度：12472准确TRAIN任务锚点；仅当任务、参考、anchor ID、codec、证明和数组哈希完全一致时复用最新11960份缓存；512新锚点各39耦合，共19968新调用。原计算及未知上界继承，缓存不称免费新计算或物理认证。
- 对照：强结构样条、旧12144 Diffusion、全部TRAIN重新拟合的50/50组加权条件均值、更新Diffusion。均值lambda10和时间基固定，不让基线只使用旧数据。均值无网络调用；网络各16步DDIM，float64采样状态/float32网络。
- 任务：原DEV4+NEW_VAL8，三种子20261919/23/29；每方法每任务5候选，共720候选、144预选执行/重放。方法次序轮换。每候选同15秒、113耦合和15872积分步上限；共同目标保持碰撞引导位于最后干净去噪步，未改成多步反馈引导。
- 选择：合格候选中最小冻结目标归一化误差，预选后真实67力矩执行，失败不替补。教师轨迹不作为模型输入或候选。
- 诊断：全部比较及选择结束后，预定第一种子候选0，各方法/任务分别raw和共同平滑限位后独立验证，96次；仅诊断不改选择。
- 资源：9000秒包含来源检查、加载、准备、训练、smoke、诊断和审计；为smoke保留4200秒，最后诊断最多600秒；2 CPU线程、20GiB。达到预算如实BLOCKED，不能退款旧失败或无限追加。

## 验收门及失败解释

C1：12688 TRAIN每行实际消费且权重改变、保存重载与来源审计PASS；新增模型每种子原DEV至少18/20、新验证至少36/40合格，全部12+24=36选定执行重放、零候选数值错误。原DEV和NEW_VAL分别报告。软件检查不能代替此验收。

C2：仅NEW_VAL8按任务配对，每任务15候选修正前目标归一化误差取中位数；对强样条及更新均值两者，新/基线比值中位数≤.85、任务bootstrap几何均值95%上界<1；C1通过且NEW_VAL候选/执行合格数不退化。bootstrap10000次，seed20261971。原DEV辅助回归，不把候选当独立任务。旧模型配对作为诊断。

若C1通过C2失败，机制可行仍成立、优势不成立，可以继续有界合格扩库；不围绕查询/时间小差异追加调参。若raw目标仍差而共同引导成功，继续报告网络和修正器的不同贡献。若准备/训练失败，保留新模型依赖BLOCKED，强样条/旧模型/均值继续独立可做部分。无自动最终TEST、strict_multimodal、十万或旧生产规模。
