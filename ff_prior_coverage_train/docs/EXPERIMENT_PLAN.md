# 新覆盖数据的冻结编码器接续训练

本协议在qualified_coverage_001结果及新训练结果之前冻结。只有该数据作业实际退出、数据门槛与原始审计通过，才由队列启动。保留原冻结DEV和旧结果，不启动最终TEST或十万条任务。

实际读取全体合格索引，预期12096–12144 TRAIN、原48 VAL。编码器、条件均值和标准化完全沿用已验证10k模型，只使用原10000 TRAIN拟合的表示；新增数据不重新拟合编码器。新训练从10k实际权重开始，优化器重新初始化，6000次更新、batch64、lr2e-4、seed20261501、v预测和0.05局部耦合目标损失。全体合格TRAIN均须实际消费，保存逐行计数和权重更新、重新加载证据。VAL仅诊断，不选检查点，不参与梯度。另记录新样本在固定表示下的重建误差，不能以表示近似代替物理准入。

旧敏感度只有在编码器、任务哈希、锚点ID、实际数组完全相同且原39次差分校验通过时按原字节复用；缓存损坏或不一致须失败关闭，不偷偷转成近邻缓存。只为新增任务计算34方向局部近似，保留步长减半和混合方向校验及遗漏方向诊断。旧调用记历史缓存成本，本次新调用单列；旧001失败和最多39次未知额外调用保留。缓存导入不运行物理，不能称为新计算或完整潜变量梯度。

5400秒新阶段活跃预算（与已结束的10k阶段历史成本分开），2线程，20GiB新增文件，预留1200秒给独立基线及执行。队列最多等待6000秒，固定父进程和run身份，父任务不通过则不启动。源代码、软件测试证明、父所有结果及冻结任务按哈希绑定。未知中断不自动重做预留工作。

冻结DEV仍为4目标×3种子20261219/20261223/20261229×5候选×4方法：强结构样条、旧10k Diffusion、固定10k条件均值、新接续Diffusion。各候选15秒、113耦合调用、15872积分区间，16 DDIM步及相同目标保持碰撞引导；按最低归一化目标误差选一条真实执行及独立重放，失败不替补，最多240候选/48选定执行。方法顺序按任务轮换。时间与查询只辅助记录，候选预算一致，不要求相对效率胜出。

通过条件：全体实际TRAIN消费、权重改变和重载、精确敏感度全部通过；新Diffusion各种子≥18/20合格、每目标可达、12/12选定执行重放；无数值ERROR、原始证据审计及旧文件保护通过。依赖失败保留BLOCKED并继续独立基线。成功率打平不得称优势；接续训练同时增加了数据和更新，不能作数据规模单因素因果结论。此阶段网络仍不编码障碍，避障能力须来自实测共同引导，不宣称学到新绕行类别。

终端：`./ff_prior_coverage_train/queue.ps1 status`（仅接续派发）；`./ff_prior_coverage_train/job.ps1 status`、`report`、`resume`（实际训练与DEV）。
