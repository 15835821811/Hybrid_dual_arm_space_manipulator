## 训练诊断意味着什么

200次更新完成；权重实际改变，保存重载误差0；150 TRAIN和30 VAL沿用原划分。训练残差RMS为0.033820 rad，原轨迹相对初态RMS为0.052296 rad，公共初始化减少了需要学习的轨迹幅度。

VAL在最高噪声处的残差去噪RMSE为0.035132 rad；不预测任何残差、直接使用公共初值时，针对数据集控制点的RMSE为0.038419 rad。最高噪声诊断改善约8.56%，幅度有限；打乱条件后的RMSE为0.040746 rad，说明模型利用了部分条件信息，但仍不足以支持5 mm目标精度。

这些误差针对保存的控制点轨迹。不同轨迹可能到达相近目标，控制点重建更准确与末端目标更准确不是同一件事。因此不能把8.56%的去噪改善写成规划收益，也不能只看训练完成或loss下降就扩大运行规模。
